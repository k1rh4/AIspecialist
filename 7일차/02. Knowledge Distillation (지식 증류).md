- Teacher - student 개념이다.
- **Knowledge Distillation(KD, 지식 증류)**은 큰 모델(Teacher)이 학습한 지식을 작은 모델(Student)에게 전달하는 학습 기법이야.
- Pruning이 기존 모델의 가중치를 제거하는 방식이라면, KD는 작은 모델을 별도로 학습시켜 큰 모델의 성능을 최대한 따라가도록 만드는 방식이야.
- 작은 모델은 보통 학습이 잘되지 않는다.  -> 학습이 잘되려면 redundency가 필요하다.

## 4. Pruning과 Knowledge Distillation의 차이

|구분|Pruning|Knowledge Distillation|
|---|---|---|
|방식|불필요한 가중치 제거|작은 모델을 학습|
|기존 모델 구조|보통 유지하거나 일부 축소|Student 구조를 별도로 설계|
|학습 필요 여부|Post-Training 방식은 필수 아님|Student 학습 필요|
|Teacher 모델|필요 없음|필요|
|결과|Pruned Model|Trained Student Model|
