# Input Sparsity
- Conv -> ReLU를 거치게되면 ReLU자체가 0이하는 0, 0보다 크면선형 
- 그러면 Conv-ReLU를 거친 행렬은 0 이 많음.
- 그래서 이 0이 많은 행렬도 푸루닝을 해주면 효율적일수있다.

# LLM Pruning 
- LLM에서 중요도가 낮거나 중복된 가중치를 제거해 모델을 경량화하는 기술이야.
- OBD 테크닉을 베이스로한다. 
	- 특정 시냅스를 제거했을때 발생하는 에러를 모니터링하고 이 에러를 줄이는 방향으로 모델링하자
	- 가중치 제거 시 Loss가 얼마나 증가하는지 계산
- 학습이 된모델을 이용하는데 학습이 된 모델이라는것은 gradiant 값이 0에 수렴해 있다고 가정한다.
- Hessian(헤시안)은 Loss가 가중치 변화에 얼마나 민감한지를 나타내는 2차 미분 값이야.
#### OBD vs OBS 비교표
OBD와 OBS는 모두 Hessian(2차 미분)을 이용해 가중치를 제거할 때 Loss가 얼마나 증가하는지 예측하는 Pruning 기법이야.

| 구분         | OBD                  | OBS                   |
| ---------- | -------------------- | --------------------- |
| 정식 명칭      | Optimal Brain Damage | Optimal Brain Surgeon |
| 공통 목적      | 불필요한 가중치 제거          | 불필요한 가중치 제거           |
| 중요도 기준     | Loss 증가량 예측          | Loss 증가량 예측           |
| Hessian 활용 | 대각 성분 \(H_{ii}\)     | 역행렬 \(H^{-1}\)        |
| 가중치 간 상관관계 | 무시 (대각 근사)           | 고려                    |
| 가중치 제거 후   | 다른 가중치를 그대로 유지       | 다른 가중치를 보정            |
| 계산 비용      | 상대적으로 낮음             | 상대적으로 높음              |
| 정확도 보존 가능성 | 상대적으로 낮음             | 상대적으로 높음              |
| 구현 난이도     | 비교적 쉬움               | 어려움                   |

# SparseGPT 
- SparseGPT는 OBS(Optimal Brain Surgeon)의 아이디어를 LLM 같은 대규모 모델에 적용할 수 있도록 효율화한 Pruning 기법이야.
- 핵심은 중요도가 낮은 가중치를 제거하면서, 남아 있는 가중치를 보정해 모델 성능 저하를 최소화하는 것이야.
- GPTQ - (퀀타이제이션) 과 완전히 동일한데 하나는 양자화, 하나는 푸루닝이다.



# Wanda (실습)
- activation 도 고려해보자! 간단하게 안되나? 
- input을 관찰한다. 보통 얼마정도 곱해지는지 관찰하고 Weight 글 곱한다.
	- 이값은 어떻게 아는가? -> 처음 입력데이터로 캘리브레이션을 해야한다. 
	- 일관된 패턴이 나오냐? -> 관찰해보면 나온다.
- 그리고 그 weight로 곱하는 표를 만든다 (Weight Importance)
- 그걸 기준으로 푸루닝을 한다.
