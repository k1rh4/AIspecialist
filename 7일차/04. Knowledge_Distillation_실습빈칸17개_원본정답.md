```python
def train_knowledge_distillation(teacher,
                                 student,
                                 train_loader,
                                 epochs,
                                 learning_rate,
                                 T,  # temperature
                                 soft_target_loss_weight,
                                 ce_loss_weight):
    ce_loss = nn.CrossEntropyLoss()
    optimizer = optim.Adam(student.parameters(), lr=learning_rate)
    scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, epochs * len(train_loader))

    teacher.eval()  # Teacher set to evaluation mode
    student.train() # Student to train mode

    for epoch in range(epochs):
        running_loss = 0.0
        for inputs, labels in train_loader:
            inputs, labels = inputs.cuda(), labels.cuda()

            optimizer.zero_grad()

            ##################### YOUR CODE STARTS HERE #####################
            # Forward pass with the teacher model - do not save gradients here as we do not change the teacher's weights
            with torch.no_grad():
                teacher_logits = teacher(inputs)   ### [B,C]

            # Forward pass with the student model
            student_logits = student(inputs)

            # Soften the student logits by applying softmax
            # Hint: nn.functional.softmax()
            soft_targets = nn.functional.softmax(teacher_logits / T, dim = -1)
            student_prob = nn.functional.softmax(student_logits / T, dim = -1)

            # Calculate the soft targets loss. Scaled by T**2 as suggested by the authors of the paper "Distilling the knowledge in a neural network"
            soft_targets_loss = torch.sum(soft_targets * (soft_targets.log() - student_prob.log()), dim=1).mean() * (T**2)

            # Calculate the true label loss
            label_loss = ce_loss(student_logits, labels)

            # Weighted sum of the two losses
            loss = soft_target_loss_weight * soft_targets_loss + ce_loss_weight * label_loss
            ##################### YOUR CODE ENDS HERE #######################

            loss.backward()
            optimizer.step()
            scheduler.step()

            running_loss += loss.item()

        print(f"Epoch {epoch+1}/{epochs}, Loss: {running_loss / len(train_loader)}")
```

| 순서 | 문제본 빈칸 | 정답본 코드 |
|---:|---|---|
| 1 | `teacher_logits =` | `teacher_logits = teacher(inputs)` |
| 2 | `student_logits =` | `student_logits = student(inputs)` |
| 3 | `soft_targets =` | `soft_targets = nn.functional.softmax(teacher_logits / T, dim = -1)` |
| 4 | `student_prob =` | `student_prob = nn.functional.softmax(student_logits / T, dim = -1)` |
| 5 | `soft_targets_loss =` | `soft_targets_loss = torch.sum(soft_targets * (soft_targets.log() - student_prob.log()), dim=1).mean() * (T**2)` |
| 6 | `label_loss =` | `label_loss = ce_loss(student_logits, labels)` |
| 7 | `loss =` | `loss = soft_target_loss_weight * soft_targets_loss + ce_loss_weight * label_loss` |

### ④ 흐름 이해
- Teacher의 출력은 `torch.no_grad()`로 계산하므로 Teacher 가중치는 업데이트하지 않습니다.
- `T`로 나눈 logits에 Softmax를 적용하여 부드러운 확률분포를 얻습니다.
- `soft_targets_loss`는 Teacher와 Student의 확률분포 차이를 계산하고 `T**2`로 보정합니다.
- `label_loss`는 실제 라벨과 Student 예측 사이의 CrossEntropy입니다.
- 두 손실을 가중합한 다음 Student에 대해서만 역전파합니다.

## 검증 및 유의사항
- 문제본과 정답본의 위 3개 함수는 같은 이름으로 매칭했으며, 빈칸 위치마다 정답본의 해당 줄을 직접 대조했습니다.
- 원본 셀의 Python 소스는 그대로 옮겼습니다. 함수가 사용하는 모델, 학습 데이터 및 CUDA 환경 설정은 노트북의 다른 셀에 있으므로 위 함수 블록만 단독 실행할 수는 없습니다.
- 주석 및 추가 설명은 시험 대비용 해설이며, 정답본의 공식 해설을 그대로 인용한 것은 아닙니다.
- 학습을 위한 코드 정리 자료로서 **모델 학습을 실제 재실행한 결과는 아닙니다.**
