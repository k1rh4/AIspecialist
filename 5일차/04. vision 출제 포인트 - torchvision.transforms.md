## 1. 전체 함수 종합표

| 구분     | 함수                              | 핵심 역할          |
| ------ | ------------------------------- | -------------- |
| 전처리    | `T.Compose()`                   | 여러 변환 연결       |
| 전처리    | `T.RandomCrop()`                | 랜덤 자르기         |
| 전처리    | `T.RandomHorizontalFlip()`      | 좌우 반전          |
| 전처리    | `T.Resize()`                    | 이미지 크기 변경      |
| 전처리    | `T.ToTensor()`                  | 이미지 → 텐서       |
| 전처리    | `T.Normalize()`                 | 평균·표준편차 정규화    |
| 차원 변경  | `.permute()`                    | 여러 차원 순서 변경    |
| 차원 변경  | `.transpose()`                  | 두 차원 맞교환       |
| 차원 변경  | `.unsqueeze()`                  | 차원 하나 추가       |
| 차원 변경  | `np.expand_dims()`              | NumPy 배열 차원 추가 |
| 형식 변환  | `torch.from_numpy()`            | NumPy → Tensor |
| 픽셀 처리  | `np.clip()`                     | NumPy 값 범위 제한  |
| 픽셀 처리  | `.clamp()`                      | Tensor 값 범위 제한 |
| 이미지 생성 | `np.zeros()`                    | 0으로 채운 이미지 생성  |
| 이미지 생성 | `np.random.randn()`             | 정규분포 난수 생성     |
| 크기 변경  | `F.interpolate()`               | 텐서 리사이즈        |
| 시각화    | `torchvision.utils.make_grid()` | 이미지 격자 생성      |
| 시각화    | `denormalize_cifar10()`         | 정규화 복원         |
| 시각화    | `overlay_heatmap_on_image()`    | 히트맵 합성         |

`denormalize_cifar10()`과 `overlay_heatmap_on_image()`는 torchvision 표준 함수가 아니라 실습에 정의된 사용자 함수야.

## 2. 모델별 핵심 사용 함수

|모델|주요 함수|특징|
|---|---|---|
|ResNet18|`RandomCrop`, `RandomHorizontalFlip`, `ToTensor`, `Normalize`|학습 이미지 증강|
|ViT|`RandomCrop`, `RandomHorizontalFlip`, `ToTensor`, `Normalize`|ResNet18과 유사|
|DETR|`Resize`, `ToTensor`, `Normalize`, `unsqueeze`|입력 크기와 배치 형태 조정|
|U-Net|`zeros`, `randn`, `clip`, `expand_dims`, `from_numpy`|합성 이미지와 마스크 생성|

가장 중요한 차이: ResNet18과 ViT는 이미지 데이터 증강을 사용하고, DETR은 입력 이미지를 모델에 맞게 전처리하며, U-Net 실습은 NumPy를 이용해 이미지와 정답 마스크를 생성해.

## 3. 시험에 나올 만한 대표 코드

### ResNet18 / ViT — 학습 데이터 증강

```
train_tfms = T.Compose([    T.RandomCrop(32, padding=4),    T.RandomHorizontalFlip(),    T.ToTensor(),    T.Normalize(CIFAR10_MEAN, CIFAR10_STD),])
```

암기 순서: Crop → Flip → Tensor → Normalize

### DETR — 입력 이미지 전처리

```
transform = T.Compose([    T.Resize(800),    T.ToTensor(),    T.Normalize(        [0.485, 0.456, 0.406],        [0.229, 0.224, 0.225]    )])
```

암기 순서: Resize → Tensor → Normalize

### U-Net — 이미지 및 마스크 생성

```
img = np.zeros((self.image_size, self.image_size), dtype=np.float32)mask = np.zeros_like(img)img = mask + 0.2 * np.random.randn(    self.image_size, self.image_size).astype(np.float32)img = np.clip(img, 0.0, 1.0)img = np.expand_dims(img, axis=0)mask = np.expand_dims(mask, axis=0)img = torch.from_numpy(img)mask = torch.from_numpy(mask)
```

암기 순서: Zeros → Noise → Clip → Expand → Tensor

### ResNet18 / ViT — 시각화 크기 변경

```
cam_resized = F.interpolate(    cam,    size=(32,32),    mode='bilinear',    align_corners=False)[0,0].cpu()
```

이 코드는 ResNet18의 Grad-CAM 부분이야. ViT에서도 Attention Map에 `F.interpolate()`를 사용해.

## 4. 꼭 기억해야 할 함수 차이

|비교|차이|
|---|---|
|`Resize` vs `interpolate`|이미지 전처리 변환 vs 텐서 크기 변경|
|`ToTensor` vs `from_numpy`|PIL/NumPy 이미지 변환과 필요시 값 스케일링 vs NumPy 배열의 텐서 변환|
|`permute` vs `transpose`|여러 차원 재배열 vs 두 차원 교환|
|`unsqueeze` vs `expand_dims`|PyTorch 차원 추가 vs NumPy 차원 추가|
|`clip` vs `clamp`|NumPy 값 제한 vs PyTorch 값 제한|
|`Normalize` vs `denormalize`|정규화 vs 원래 값 범위 복원|

## 5. 최종 시험 암기 우선순위

1순위 — 반드시 암기

`Compose`, `RandomCrop`, `RandomHorizontalFlip`, `Resize`, `ToTensor`, `Normalize`

2순위 — Shape 관련 코드

`permute`, `transpose`, `unsqueeze`, `expand_dims`, `from_numpy`

3순위 — 이미지 생성 및 시각화

`interpolate`, `clip`, `clamp`, `zeros`, `randn`, `make_grid`, `denormalize`

특히 `Normalize`는 다음 식을 함께 외워두는 게 좋아.

\[ x_{\text{normalized}}=\frac{x-\text{mean}}{\text{std}} \]
