## 1. sklearn 사용 위치 요약

| 실습 코드    | sklearn 함수                         | 사용 목적                     |
| -------- | ---------------------------------- | ------------------------- |
| ResNet18 | `sklearn.manifold.TSNE`            | 추출한 특징 벡터를 2차원으로 축소해 시각화  |
| ViT      | `sklearn.metrics.confusion_matrix` | 실제 정답과 예측 결과를 비교해 혼동행렬 생성 |
| DETR     | 사용 없음                              | —                         |
| U-Net    | 사용 없음                              | —                         |

## 2. ResNet18 — TSNE

원본 코드에서 발췌

```
from sklearn.manifold import TSNEtsne = TSNE(    n_components=2,    perplexity=30,    learning_rate='auto',    init='pca',    random_state=42)X_2d = tsne.fit_transform(X_feat)
```

목적: ResNet18에서 추출한 고차원 특징 벡터를 2차원 좌표로 변환하여 시각화합니다.

- `n_components=2` : 2차원으로 축소
    
- `perplexity=30` : 주변 이웃 관계를 고려하는 설정값
    
- `init='pca'` : PCA 기반 초기화
    
- `fit_transform(X_feat)` : 실제 차원 축소 수행
    

시험에서는 특히 `TSNE`, `fit_transform()`, `n_components=2`를 기억하면 좋습니다.

## 3. ViT — confusion_matrix

onfusion_matrix  개념.
`confusion_matrix()`는 모델이 어떤 클래스를 맞혔고, 어떤 클래스를 다른 클래스로 잘못 예측했는지 각각의 개수를 계산하는 함수야.
```
cm = confusion_matrix(all_labels, all_preds)
```

![[Pasted image 20261108135446.png]]


목적: ViT가 각 클래스를 얼마나 정확하게 분류했는지 확인합니다.
- `all_labels` : 실제 정답 
- `all_preds` : 모델의 예측 결과
- `confusion_matrix()` : 실제값과 예측값의 비교표 생성
- `sns.heatmap()` : 혼동행렬을 색상 그래프로 표시

여기서 `confusion_matrix()`는 sklearn 함수이지만, `heatmap()`은 seaborn 함수입니다.

## 4. 시험 대비 핵심 정리

|함수|입력|출력|암기 포인트|
|---|---|---|---|
|`TSNE.fit_transform()`|특징 벡터|저차원 좌표|특징 시각화|
|`confusion_matrix()`|정답, 예측값|혼동행렬|분류 성능 분석|

두 함수 모두 모델을 직접 학습시키는 용도가 아니라, 학습된 모델의 결과를 분석하는 용도입니다.
