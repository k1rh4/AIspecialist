## 빈칸 정답만 빠르게 복습

| 문제 구간 | 정답 |
|---|---|
| LayerNorm 평균 | `mean` |
| LayerNorm 분산 | `var` |
| LayerNorm Scale | `self.scale` |
| LayerNorm Shift | `self.shift` |
| FeedForward 확장 | `4` |
| FeedForward 활성화 | `GELU` |
| FeedForward 축소 전 차원 | `4` |
| Transformer Attention | `self.att` |
| Transformer FF | `self.ff` |
| Token Embedding 어휘 크기 | `vocab_size` |
| Position Embedding 문맥 크기 | `context_length` |
| Output Head 어휘 크기 | `vocab_size` |
| 임베딩 합산 | `pos_embeds` |
| Transformer 통과 | `self.trf_blocks` |
| Logits 출력 | `self.out_head` |
| 생성 시 기울기 비활성화 | `no_grad` |
| 마지막 시점 | `-1` |
| 다음 토큰 | `argmax` |
| 토큰 연결 | `cat` |

**주의:** 코드 블록 일부는 원본 함수의 일부분만 발췌한 것이므로, 각 블록을 독립 실행하는 용도가 아니라 빈칸 복습용이다.
