```
def generate_text_simple(model, idx, max_new_tokens, context_size):
    """
    간단한 텍스트 생성 루프
    현재 문맥을 넣어 다음 토큰을 예측하고, 이를 다시 문맥에 추가하여 반복함
    """
    # idx: 현재 문맥의 토큰 인덱스들 (Batch, Time)
    for _ in range(max_new_tokens):

        # 모델이 지원하는 최대 길이(context_size)를 넘지 않도록 자름
        idx_cond = idx[:, -context_size:]

        # 모델 예측 (기울기 계산 불필요)
        with torch.no_grad():  ## 
            logits = model(idx_cond)
             # 이때 logits의 shape은 (batch_size, num_tokens, vocab_size) 이럼

        # 마지막 타임스텝의 예측값만 가져옴 (다음 단어 예측이므로)
        # (batch, n_token, vocab_size) -> (batch, vocab_size)
        logits = logits[:, -1, :]

        # 가장 확률(로짓값)이 높은 토큰 선택 (Greedy Decoding)
        idx_next = torch.argmax(logits, dim=-1, keepdim=True) 

        # 예측된 토큰을 현재 시퀀스 뒤에 이어 붙임
        idx = torch.cat((idx, idx_next), dim=1) 

    return idx
```
- 위 코드 설명 
	- torch.no_grad() - 그라이안트는 모델 학습에만 쓰이기에 추론땐 필요없음
		- pytorch는 기본적으로 기울기를 계산해서 no_grad를 명시해줘야함.
		![[Pasted image 20261103090609.png]]
	- logits = model(index_count) 
		- 이때 logits의 shape은 (batch_size, num_tokens, vocab_size) 이럼
	- logits 이 뭔데?  모델에서 output... 토큰 갯수만큼 차원을 가지게 된다.
		![[Pasted image 20261103090828.png]]
	- torch.argmax() 으로 확율이 가장 높은걸 뽑고.
	- torch.cat() 으로 원하는길이가 될때까지 이어 붙인다. 
	- out_head 은 vocap_size 만큼 풀어져야한다. 
	- idx_next = torch.argmax(logits, dim=-1, keepdim=True 
		- 에서 dim=-1은 마지막 차원을 입력한다는 이야기.
