# 학습 포인트!
 - 학습은 손실을 바탕으로 weight을 조절하는 과정이다.
 - optimizer.zero_grad()로 초기화  -> pyorch 가 자동으로 누적.  loss 계산 전에 초기화해 함
 - 손실 값을 얻기 위해 logits 값을 모델에서 input_batch에서 가져오고, 
	 - 이때 손실을 비교하기 위해 target_batch (정답지)와 비교하여 값을 계산한다.
 - 이값을 바탕으로 loss 값을 뽑아낸다. (이대 평탄화 작업필요)
 - 손실 값을 바탕으로 뒤로가면서 가중치 업데이트
 - optimizer.step으로 weight값 계산하여 반영
 - 끝!
