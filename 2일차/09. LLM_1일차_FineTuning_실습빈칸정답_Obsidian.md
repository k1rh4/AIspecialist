## Chapter 7 — Direct Preference Optimization (DPO)

[원본](https://github.com/heury/llm_hands_on/blob/main/Chapter_7_Exercise_Follow_Instructions_dpo.ipynb)

### 1. Logits / Labels 시프트

```python
# TODO: 자동회귀 시프트 인덱스를 채우세요.
# 힌트: labels는 1칸 앞당기고 logits는 마지막 시점을 제외해 정렬합니다.
labels = labels[:, 1:].clone()
logits = logits[:, :-1, :]
```

### 2. 정답 토큰의 Log Probability 추출

```python
log_probs = F.log_softmax(logits, dim=-1)

# TODO: gather의 input 텐서를 채우세요.
# 힌트: raw logits가 아닌 log_probs에서 정답 위치를 gather해야 합니다.
selected_log_probs = torch.gather(
    input=log_probs,
    dim=-1,
    index=labels.unsqueeze(-1)
).squeeze(-1)
```

### 3. Policy의 선호 로그 비율

```python
# TODO: 정책 모델 chosen 로그확률 변수를 채우세요.
# 힌트: chosen - rejected 순서로 빼야 preference 방향이 맞습니다.
model_logratios = model_chosen_logprobs - model_rejected_logprobs
```

### 4. Reference의 선호 로그 비율

```python
# TODO: 레퍼런스 모델 chosen 로그확률 변수를 채우세요.
# 힌트: reference도 chosen - rejected 순서를 동일하게 유지합니다.
reference_logratios = reference_chosen_logprobs - reference_rejected_logprobs
```

### 5. 두 모델의 선호 차이

```python
# TODO: DPO logits 차감 대상을 채우세요.
# 힌트: policy 비율에서 reference 비율을 빼는 형태입니다.
logits = model_logratios - reference_logratios
```

### 6. DPO Loss 계산

```python
# TODO: DPO 손실 함수명을 채우세요.
# 힌트: beta * logits에 logsigmoid를 적용해 손실을 계산합니다.
losses = -F.logsigmoid(beta * logits)
```

## 핵심 암기표

| 구분 | 핵심 정답 |
|---|---|
| 분류 데이터 자르기 | `self.max_length` |
| 분류 패딩 | `pad_token_id` |
| 분류 정답 컬럼 | `"Label"` |
| 파라미터 동결 | `requires_grad = False` |
| 분류 Head | `out_features=num_classes` |
| 마지막 Transformer | `trf_blocks[-1]` |
| 특정 층 학습 허용 | `requires_grad = True` |
| LoRA A/B | `(in_dim, rank)`, `(rank, out_dim)` |
| LoRA Forward | `(self.alpha/self.rank) * (x @ self.A @ self.B)` |
| LoRA 출력 합산 | `self.linear(x) + self.lora(x)` |
| LoRA 타입 판별 | `isinstance(module, torch.nn.Linear)` |
| LoRA 주입 | `replace_linear_with_lora(...)` |
| SFT Input/Target | `padded[:-1]` / `padded[1:]` |
| SFT 마스킹 | `indices[1:]` |
| DPO 시프트 | `labels[:, 1:]`, `logits[:, :-1, :]` |
| DPO 로그 확률 추출 | `torch.gather(input=log_probs, ...)` |
| DPO 선호 비교 | `chosen - rejected` |
| DPO 최종 Loss | `-F.logsigmoid(beta * logits)` |

> 주의: 1일차 전체 Fine-tuning 노트북의 정확한 **전체 빈칸 개수**를 확정하기 위한 자동 완전 대조는 수행하지 못했습니다. 이 파일은 웹에서 원문을 직접 확인한 TODO 구간만 수록합니다.
