
# 핵심
- Lora fine tuning은 기존의 큰 행렬 모델은 유지.
- 새로운 작은 행렬을 만듦. (이때 기존 모델의 layer의 차원을 가져와야함. )
	- LinearWithLoRa(nn.Module) -> Module에 기존 모델의 feature 크기가 있음. 
- 기존 모델의 행크기가 동일한 작은 행렬을 만듦. (rank를 지정하므로써 얼마나 작은 차원으로만들지 정함)
- 새롭게 만든 행렬부터 내적하여 학습 시작.
- 
### 크게 3단계
- **loRALayer 만들기** 
	- 행렬 선언
	- 행렬 초기화
	- forward 로 행렬 계산 
- **LinearWithLoRA**
	- LoRALayer 클래스 가져오기
	- 기존 linear 에 lora 붙이기 (찾을수 있다면)
- **replace_linear_with_lora**
	- 기존 모델에서 Linear 부분 찾기 
	- 기존 레이어를 LORA로 교체.
	- 재귀 호출

# 코드설명
```
self.A = nn.Parameter(
    torch.empty(in_dim, rank)
)
```

```
in_dim = 768
out_dim = 768
rank = 8
alpha = 16
```
nn.Parameter는 작은 행렬 값을 만들어서 압축을 진행함.
위와 같이 dim이 768이고 rank가 8 이면, 768 차원을 8차원으로 압축하는 역할을 함.
nn.Parameter를 사용했으므로 학습 가능한 파라미터로 등록.


```
nn.init.kaiming_uniform_(
    self.A,
    a=math.sqrt(5)
)
```
위 코드는 행렬을 초기화함. 

# 왜 임의 값으로 초기화할까?
신경망은 처음부터 적절한 Weight 값을 가지고 시작하지 않기 때문에 학습을 시작할 수 있도록 초기값을 설정해야 해.
여기서는 Kaiming Uniform 초기화 방법을 사용한 거야.


```
self.B = nn.Parameter(
    torch.zeros(rank, out_dim)
)
```
이후 B행렬 생성. 0으로 초기화 .
A는 값이 있는 채로,,, B는 0으로 초기화 한 채로 시작. 

# 왜 0으로 초기화할까?
처음 학습을 시작할 때 LoRA의 영향력을 0으로 만들기 위해서야.
따라서 학습 시작 시점에는 기존 Linear 레이어의 출력과 LoRA를 적용한 출력이 동일해.


```
self.alpha = alpha
self.rank = rank
```
이 두 값은 LoRA의 학습 영향력을 조절하는 데 사용돼.
- alpha: LoRA의 영향력을 조절하는 값
- rank: A와 B 행렬의 차원을 결정하는 값

이제 실제로 LoRA 연산을 수행하는 부분이야.
```
def forward(self, x):
    x = (self.alpha / self.rank) * (
        x @ self.A @ self.B
    )
    return x
```

# LinearWithLoRA 클래스

```
class LinearWithLoRA(nn.Module):

    def __init__(self, linear, rank, alpha):
        super().__init__()

        self.linear = linear

        self.lora = LoRALayer(
            linear.in_features,
            linear.out_features,
            rank,
            alpha
        )
```
이 클래스는 기존 Linear 레이어에 LoRA를 추가하는 역할을 해.
여기서 중요한 부분은 다음 코드야.

```
self.linear = linear
```
기존 GPT에 있던 Linear 레이어를 그대로 보관하는 거야.
예를 들어 기존 GPT에 다음 코드가 있었다고 해보자.

```
self.W_query = nn.Linear(768, 768)
```

이 Linear 레이어를 통째로 전달받는 거야.


그리고 다음 코드로 LoRA를 추가해.
```
self.lora = LoRALayer(
    linear.in_features,   ## 입력 features는 차원. 768차원 이런거임.
    linear.out_features,  ## 출력 features는 차원, 768 차원..이런거임. 
    rank,
    alpha
)
```

# replace_linear_with_lora()

이 함수는 GPT 모델 내부에 있는 Linear 레이어들을 찾아서 LoRA가 적용된 레이어로 교체해.
```
def replace_linear_with_lora(model, rank, alpha):

    for name, module in model.named_children():

        if isinstance(module, torch.nn.Linear):

            setattr(
                model,
                name,
                LinearWithLoRA(module, rank, alpha)
            )

        else:
            replace_linear_with_lora(
                module, rank, alpha
            )
```

## 6. 그런데 이 코드에서 한 가지 빠진 것이 있어!

아주 중요해.

현재 코드만으로는 기존 Linear의 Weight가 자동으로 고정되지 않아.

```
self.linear = linear
```

이렇게 기존 Linear를 보관하면 기존 Weight도 여전히 학습 가능한 상태야.
LoRA 방식대로 기존 Weight를 고정하려면 다음 코드를 추가해야 해.

python

```
class LinearWithLoRA(nn.Module):

    def __init__(self, linear, rank, alpha):
        super().__init__()

        self.linear = linear

        # 기존 Linear의 Weight 고정
        for param in self.linear.parameters():
            param.requires_grad = False

        self.lora = LoRALayer(
            linear.in_features,
            linear.out_features,
            rank,
            alpha
        )

    def forward(self, x):
        return self.linear(x) + self.lora(x)
```

이렇게 해야 기존 Linear의 Weight는 유지되고 LoRA의 A와 B만 학습돼.
