## 2. 코드 흐름 암기

### 9일차 — 문서 → 청크 → 인덱스 → 검색

```python
# 문서를 읽고 청크로 분할하여 벡터 인덱스에 저장
from llama_index.core import SimpleDirectoryReader, VectorStoreIndex
from llama_index.core.node_parser import SentenceSplitter

documents = SimpleDirectoryReader("data").load_data()
parser = SentenceSplitter(chunk_size=1024, chunk_overlap=200)
index = VectorStoreIndex.from_documents(
    documents=documents,
    transformations=[parser]
)
retriever = index.as_retriever(similarity_top_k=2)
nodes = retriever.retrieve("질문")
```

- `SimpleDirectoryReader(...).load_data()`: 로컬 파일을 문서 객체로 로딩
- `SentenceSplitter(...)`: 문서 청크 크기 및 중첩 지정
- `VectorStoreIndex.from_documents(...)`: 인덱스 생성
- `as_retriever(similarity_top_k=2)`: 상위 2개 검색을 위한 Retriever 생성
- `retrieve("질문")`: 질문과 연관된 노드 검색

> [!warning] 실행 환경
> 실제 `VectorStoreIndex` 생성 및 `retrieve()`는 설정된 임베딩 모델에 따라 외부 API가 필요할 수 있다. **메서드 문법 암기**와 **오프라인 실행 가능 여부**는 구분하자.

### 10일차 — MCP 도구를 에이전트에 연결

```python
mcp_client = BasicMCPClient(external_mcp_server)
mcp_tool = McpToolSpec(client=mcp_client)
tools = await mcp_tool.to_tool_list_async()

agent = FunctionAgent(
    name="Agent",
    description="An agent that can work with Our Knowledge Graph api.",
    tools=tools,
    llm=llm,
    system_prompt=SYSTEM_PROMPT,
)
```

- `BasicMCPClient`: MCP 서버 클라이언트
- `McpToolSpec`: MCP 도구 사양을 LlamaIndex 에이전트에서 쓸 수 있도록 연결
- `to_tool_list_async()`: MCP 서버 도구를 에이전트용 도구 목록으로 변환
- `FunctionAgent(..., tools=tools, ...)`: 도구를 사용하는 에이전트 구성

> [!warning] 환경 제약
> MCP 서버 연결과 LLM 호출은 실습 환경 및 네트워크 상태에 영향을 받는다. 오프라인 시험에서는 **실행 결과보다는 메서드명과 인자 구성 빈칸**이 현실적인 후보라는 추정이다.
