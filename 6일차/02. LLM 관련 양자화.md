LLM은  PTQ 방식을 써야해.

# SmoothQuant  (** 교수님이 중요도 표시함)
- 특정 위치에 아웃라이어가 있더라. 
- weight 와 Activiation 두개가 있을때 activation 의 outlier를 weight로 옮기는 기술.
- SmoothQuant는 Activation의 큰 값(Outlier)을 줄이고, 그 부담을 Weight 쪽으로 옮겨서 양자화 오차를 줄이는 기술이야.
- 특히 LLM에서 Weight와 Activation을 모두 INT8로 양자화하는 W8A8을 효율적으로 구현하기 위해 사용하는 방법이야.

## 1. 왜 SmoothQuant가 필요할까?

앞에서 배운 내용을 연결해 보자.
- Weight: 모델이 학습해서 기억하고 있는 값
- Activation: 입력에 따라 Layer에서 계산되는 값
- LLM에서는 Activation에 유난히 큰 값인 **Outlier(이상치)**가 등장할 수 있어.
	- activation = [0.2, 0.5, 0.8, 100.0]

- `X / S` → Activation 크기를 줄임
- `S × W` → Weight 크기를 늘림
- 전체 곱셈 결과 → 동일하게 유지

# QuaRot
- 로테이션 메트릭스 
- QuaRot는 Weight와 Activation의 큰 이상치(Outlier)를 여러 차원으로 분산시켜 양자화 오차를 줄이는 기술이야.
- 중요한 점은 회전 행렬을 적절하게 적용하면 모델의 전체 연산 결과를 유지하면서 값의 분포를 바꿀 수 있다는 것이야.

안쓰는 구간을 조절한다. 
smooth transform == 전체 구간을 줄인다.
Rotation Transform == 텐서를 로테이션을 잘 회전하면 튀어나온 부분이 이동하면서 스무스 해진다. 
- 정확도가 더 올라간다는 개념.



- ```
  실습에서 다음 두 가지를 우선 암기하면 돼.
  W_ @ R1
  R1.T @ W_
  ```
- `@` : 행렬 곱셈(Matrix Multiplication)
- `.T` : 행렬 전치(Transpose). 행과 열을 서로 바꿈.
- `W_` : 기존 Weight 행렬
- `R1` : 회전 행렬

# AWQ
smooth quant 와 같은 저자임.  
Smooth quant 는 weight와 avtivate 둘다 양자화 하는 기법
AWQ는 중요한 weight 만 선별하겨 양자화 한다. 
특정 채널만 잘 선택해서 FP16으로 연산.
-> 채널 선택의 기준은 weight 를 봐서는 안된다.
-> activation을 봐야한다. <-- 이게 핵심 아이디어
-> 튜닝 파라미터가 있고이 값으로 S를 결정(scale)
