## Chapter 2 — Dataset

### 전체 흐름

`raw_text → tokenizer.encode → token_ids → input_chunk/target_chunk → GPTDatasetV1 → DataLoader → token_embeddings → position_embeddings → input_embeddings`

### 1. Token Encoding / Decoding — 정답 1·2

**원본 코드 셀의 전후 맥락**

```python
import importlib
import tiktoken

print("tiktoken version:", importlib.metadata.version("tiktoken"))

tokenizer = tiktoken.get_encoding("gpt2")

text = (
    "Hello, do you like tea? <|endoftext|> In the sunlit terraces"
     "of someunknownPlace."
)
# region  [token encoding]
integers = tokenizer.encode(text, allowed_special={"<|endoftext|>"})  # ★ 1
# endregion
print(integers)

# region  [token decoding]
strings = tokenizer.decode(integers)  # ★ 2
# endregion
print(strings)
```

**설명:** `encode`는 문자열 → 정수 토큰 ID, `decode`는 토큰 ID → 문자열. `allowed_special`이 특수 토큰을 허용합니다.

### 2. Next-token Target — 정답 3

실습은 `datas/the-verdict.txt`를 다운로드하거나 읽은 후 다음 코드를 실행합니다.

```python
with open("datas/the-verdict.txt", "r", encoding="utf-8") as f:
    raw_text = f.read()

enc_text = tokenizer.encode(raw_text)
print(len(enc_text))
enc_sample = enc_text[50:]

context_size = 4
x = enc_sample[:context_size]
y = enc_sample[1:context_size+1]  # ★ 3

print(f"x: {x}")
print(f"y:      {y}")
```

원본 출력 예:

```text
x: [290, 4920, 2241, 287]
y:      [4920, 2241, 287, 257]
```

**설명:** `x`의 각 토큰에 대응하는 `y`는 다음 위치의 토큰. `context_size+1`은 슬라이싱 끝 인덱스가 포함되지 않기 때문입니다.

### 3. GPTDatasetV1 — 정답 4·5·6

`__init__`에서 입력과 정답 청크를 만들고, `__getitem__`에서 동일한 인덱스 쌍을 반환합니다.

```python
import torch
from torch.utils.data import Dataset, DataLoader

class GPTDatasetV1(Dataset):
    def __init__(self, txt, tokenizer, max_length, stride):
        self.input_ids = []
        self.target_ids = []

        # 1. 전체 텍스트 토큰화
        token_ids = tokenizer.encode(txt, allowed_special={"<|endoftext|>"})
        assert len(token_ids) > max_length, "토큰화된 입력의 개수는 적어도 max_length+1과 같아야 합니다."

        # 2. Sliding Window
        for i in range(0, len(token_ids) - max_length, stride):
            # region [input 청크 생성]
            input_chunk = token_ids[i : i + max_length]  # ★ 4
            # endregion

            # region [target 청크 생성]
            target_chunk = token_ids[i + 1 : i + max_length + 1]  # ★ 5
            # endregion

            self.input_ids.append(torch.tensor(input_chunk))
            self.target_ids.append(torch.tensor(target_chunk))

    def __len__(self):
        return len(self.input_ids)

    def __getitem__(self, idx):
        return self.input_ids[idx], self.target_ids[idx]  # ★ 6
```

**설명:** `stride`는 다음 입력 청크의 시작 위치를 옮기는 간격. `max_length`는 각 입력/정답 청크 길이. 둘의 길이는 같아야 합니다.

### 4. DataLoader — 정답 7

위에서 정의한 `GPTDatasetV1`이 입력으로 들어갑니다. 원본에는 바로 다음 셀에 첫 번째·두 번째 배치를 꺼내는 코드가 있습니다.

```python
import tiktoken

def create_dataloader_v1(txt, batch_size=4, max_length=256,
                         stride=128, shuffle=True, drop_last=True,
                         num_workers=0):
    tokenizer = tiktoken.get_encoding("gpt2")
    dataset = GPTDatasetV1(txt, tokenizer, max_length, stride)

    # region [DataLoader 생성]
    dataloader = DataLoader(
        dataset,                 # ★ 7
        batch_size=batch_size,
        shuffle=shuffle,
        drop_last=drop_last,
        num_workers=num_workers
    )
    # endregion
    return dataloader

# 다음 원본 코드 셀

dataloader = create_dataloader_v1(
    raw_text, batch_size=1, max_length=4, stride=1, shuffle=False
)
data_iter = iter(dataloader)
first_batch = next(data_iter)
print(first_batch)
second_batch = next(data_iter)
print(second_batch)
```

**설명:** `Dataset`은 인덱스로 샘플을 주고 `DataLoader`는 그 샘플을 묶어 배치를 제공합니다. `next(data_iter)`가 다음 배치를 꺼냅니다.

### 5. Token Embedding — 정답 8·9

```python
input_ids = torch.tensor([2, 3, 5, 1])

vocab_size = 6
output_dim = 3

torch.manual_seed(123)
# region [임베딩 레이어 생성]
embedding_layer = torch.nn.Embedding(vocab_size, output_dim)  # ★ 8
# endregion

print(embedding_layer.weight)

# region [임베딩 레이어 적용]

```

**설명:** `input_ids.shape = [4]` → `token_embeddings.shape = [4, 3]`. 각 토큰 ID에 대응하는 학습 가능한 3차원 벡터를 조회합니다.

### 6. Position Embedding + 합산 — 원본의 추가 `region` 3개

> **중요:** 이전 16개 목록에서 빠져 있었지만, `exercise_answer` 원본에는 명시적으로 `region`으로 감싼 코드가 있습니다. 따라서 별도 암기 항목으로 넣었습니다.

```python
vocab_size = 50257
output_dim = 256

token_embedding_layer = torch.nn.Embedding(vocab_size, output_dim)

max_length = 4
dataloader = create_dataloader_v1(
    raw_text, batch_size=8, max_length=max_length,
    stride=max_length, shuffle=False
)

data_iter = iter(dataloader)
inputs, targets = next(data_iter)
token_embeddings = token_embedding_layer(inputs)
print(token_embeddings.shape)

context_length = max_length
# region [포지셔널 임베딩 레이어 생성]
pos_embedding_layer = torch.nn.Embedding(context_length, output_dim)  # ★ 추가 A
# endregion
# region [포지셔널 임베딩 적용]
pos_embeddings = pos_embedding_layer(torch.arange(max_length))  # ★ 추가 B
# endregion
print(pos_embeddings.shape)
# region [토큰 임베딩과 포지셔널 임베딩 합산]
input_embeddings = token_embeddings + pos_embeddings  # ★ 추가 C
# endregion
print(input_embeddings.shape)
```

**원본 출력 Shape**

| 단계 | Shape | 의미 |
|---|---|---|
| `token_embeddings` | `[8, 4, 256]` | 8개 배치 × 4개 토큰 × 256차원 |
| `pos_embeddings` | `[4, 256]` | 토큰 위치 4개 × 256차원 |
| `input_embeddings` | `[8, 4, 256]` | 위치 벡터를 각 배치에 브로드캐스팅하여 더함 |

## Chapter 3 — Attention

### 전체 흐름

`x → W_query/W_key/W_value → Q/K/V → Q @ Kᵀ → mask → softmax → dropout → attention_weights @ V → context_vec`

### 7. CausalAttention — 정답 10~15

아래는 **원본의 실제 클래스 구조와 계산 순서**입니다. 원본에 있던 장문의 설명 주석만 단축했고 연산식 및 선언은 그대로 두었습니다.

```python
import torch
import torch.nn as nn

class CausalAttention(nn.Module):
    def __init__(self, d_in, d_out, context_length, dropout, qkv_bias=False):
        super().__init__()

        # 1. Q/K/V Linear 투영
        self.W_query = nn.Linear(d_in, d_out, bias=qkv_bias)  # ★ 10
        self.W_key   = nn.Linear(d_in, d_out, bias=qkv_bias)  # ★ 10
        self.W_value = nn.Linear(d_in, d_out, bias=qkv_bias)  # ★ 10

        self.dropout = nn.Dropout(dropout)
        self.register_buffer(
            'mask',
            torch.triu(torch.ones(context_length, context_length), diagonal=1)
        )

    def forward(self, x):
        b, num_tokens, d_in = x.shape

        # region [Q, K, V 벡터 계산]
        keys = self.W_key(x)        # ★ 11: [b, num_tokens, d_out]
        queries = self.W_query(x)   # ★ 11: [b, num_tokens, d_out]
        values = self.W_value(x)    # ★ 11: [b, num_tokens, d_out]
        # endregion

        # region [어텐션 스코어(유사도) 계산]
        attn_scores = queries @ keys.transpose(1, 2)  # ★ 12
        #endregion

        # region [인과적 마스킹 (Masking) - 미래 정보 차단]
        attn_scores.masked_fill_(
            self.mask.bool()[:num_tokens, :num_tokens],
            -torch.inf  # ★ 13
        )
        # endregion

        # region [어텐션 가중치(Weights) 계산 및 스케일링]
        attn_weights = torch.softmax(
            attn_scores / keys.shape[-1]**0.5, dim=-1  # ★ 14
        )
        # endregion

        # region [드롭아웃 적용]
        attn_weights = self.dropout(attn_weights)
        # endregion

        # region [문맥 벡터(Context Vector) 생성]
        context_vec = attn_weights @ values  # ★ 15
        # endregion
        return context_vec
```

**연산 및 Shape** (`batch=2`, `num_tokens=6`, `d_in=3`, `d_out=2`):

| 단계 | Shape | 설명 |
|---|---|---|
| `x` | `[2, 6, 3]` | 2개 시퀀스, 시퀀스당 6개 토큰, 입력 벡터 3차원 |
| `keys`, `queries`, `values` | 각각 `[2, 6, 2]` | Q/K/V 각 2차원 |
| `keys.transpose(1, 2)` | `[2, 2, 6]` | 행렬 곱을 위한 마지막 두 차원 교환 |
| `attn_scores` | `[2, 6, 6]` | 6개의 Query와 6개의 Key 간 점수 |
| `attn_weights` | `[2, 6, 6]` | Key 방향(`dim=-1`)으로 정규화된 가중치 |
| `context_vec` | `[2, 6, 2]` | 각 Query의 Value 가중합 |

### 8. CausalAttention 실행 — 정답 16

실제 클래스 정의 **바로 다음 원본 코드 셀**입니다.

```python
import torch

inputs = torch.tensor(
  [[0.43, 0.15, 0.89], # Your     (x^1)
   [0.55, 0.87, 0.66], # journey  (x^2)
   [0.57, 0.85, 0.64], # starts   (x^3)
   [0.22, 0.58, 0.33], # with     (x^4)
   [0.77, 0.25, 0.10], # one      (x^5)
   [0.05, 0.80, 0.55]] # step     (x^6)
)

d_in = inputs.shape[1]
d_out = 2
batch = torch.stack((inputs, inputs), dim=0)
torch.manual_seed(123)

context_length = batch.shape[1]
print("context_length:", context_length)

ca = CausalAttention(d_in, d_out, context_length, 0.0)
context_vecs = ca(batch)  # ★ 16

print(context_vecs)
print("context_vecs.shape:", context_vecs.shape)
```

최종 출력 크기: `torch.Size([2, 6, 2])`.

### 9. MultiHeadAttentionWrapper — 추가 참고 (같은 원본 Attention 노트북)

`CausalAttention` 객체를 `num_heads`개 만들고, 각 출력 결과를 `torch.cat`으로 연결합니다.

```python
class MultiHeadAttentionWrapper(nn.Module):
    def __init__(self, d_in, d_out, context_length, dropout, num_heads, qkv_bias=False):
        super().__init__()
        assert d_out % num_heads == 0, "d_out must be divisible by num_heads"
        self.head_dim = d_out // num_heads
        self.heads = nn.ModuleList(
            [CausalAttention(d_in, self.head_dim, context_length, dropout, qkv_bias)
             for _ in range(num_heads)]
        )
        self.out_proj = nn.Linear(d_out, d_out)

    def forward(self, x):
        context_vec = torch.cat([head(x) for head in self.heads], dim=-1)
        return self.out_proj(context_vec)

# 원본 사용 예

torch.manual_seed(123)
context_length = batch.shape[1]
d_in, d_out = 3, 2
mha = MultiHeadAttentionWrapper(
    d_in, d_out, context_length, 0.0, num_heads=2
)
context_vecs = mha(batch)
print(context_vecs)
print("context_vecs.shape:", context_vecs.shape)
```

### 10. MultiHeadAttention — 추가 참고 (같은 원본 Attention 노트북)

Wrapper와 달리 `Q/K/V`를 만든 다음 `view`로 헤드 차원을 나누어 한 번에 계산합니다. **원본 코드에서 이어지는 핵심 계산 부분**입니다.

```python
# class MultiHeadAttention(nn.Module)의 __init__ 내
self.d_out = d_out
self.num_heads = num_heads
self.head_dim = d_out // num_heads
self.W_query = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_key = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_value = nn.Linear(d_in, d_out, bias=qkv_bias)
self.out_proj = nn.Linear(d_out, d_out)
self.dropout = nn.Dropout(dropout)
self.register_buffer(
    "mask",
    torch.triu(torch.ones(context_length, context_length), diagonal=1)
)

# forward(self, x) 내
b, num_tokens, d_in = x.shape
keys = self.W_key(x)
queries = self.W_query(x)
values = self.W_value(x)

keys = keys.view(b, num_tokens, self.num_heads, self.head_dim)
values = values.view(b, num_tokens, self.num_heads, self.head_dim)
queries = queries.view(b, num_tokens, self.num_heads, self.head_dim)

keys = keys.transpose(1, 2)
queries = queries.transpose(1, 2)
values = values.transpose(1, 2)
attn_scores = queries @ keys.transpose(2, 3)
mask_bool = self.mask.bool()[:num_tokens, :num_tokens]
attn_scores.masked_fill_(mask_bool, -torch.inf)
attn_weights = torch.softmax(attn_scores / keys.shape[-1]**0.5, dim=-1)
attn_weights = self.dropout(attn_weights)
context_vec = (attn_weights @ values).transpose(1, 2)
context_vec = context_vec.contiguous().view(b, num_tokens, self.d_out)
context_vec = self.out_proj(context_vec)
return context_vec
```

**차이 암기:** `CausalAttention`은 `keys.transpose(1, 2)`, 다중 헤드로 펼친 `MultiHeadAttention`은 `keys.transpose(2, 3)`입니다. `view → transpose → attention → transpose → contiguous().view` 순서가 핵심입니다.

## 최종 암기표

| 범위 | 핵심 정답 | 그 앞뒤에 오는 흐름 |
|---|---|---|
| Tokenizer | `encode`, `decode` | `get_encoding → encode → print → decode → print` |
| Next token | `enc_sample[1:context_size+1]` | `enc_text → enc_sample → x/y → print` |
| Dataset | `input_chunk`, `target_chunk` | `encode → for range → slice → tensor → append` |
| Dataset | `__getitem__` | `__len__ → __getitem__ → tuple return` |
| DataLoader | `DataLoader(dataset, ...)` | `tokenizer → GPTDatasetV1 → DataLoader → iter → next` |
| Embedding | `Embedding`, `embedding_layer(input_ids)` | `input_ids → Embedding → weight → token_embeddings` |
| Position Embedding | `pos_embedding_layer`, `torch.arange`, `+` | `token_embedding → position_embedding → add` |
| Q/K/V | `nn.Linear`, `self.W_*(x)` | `__init__ → forward → keys/queries/values` |
| Attention Score | `queries @ keys.transpose(1, 2)` | `Q/K/V → scores → mask` |
| Attention Weight | `-torch.inf`, `softmax(...dim=-1)` | `scores → masked_fill_ → softmax → dropout` |
| Context | `attn_weights @ values` | `dropout → context_vec → return` |
| Causal 실행 | `ca(batch)` | `inputs → stack → CausalAttention → ca(batch) → print` |
| Multi-head | `torch.cat`, `view`, `transpose` | `split heads → attention → merge heads` |
