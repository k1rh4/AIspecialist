# Causal Attention 방식
- GPT방식이 다음 단어를 예측하는 것으로 시작됨.
- masking을 통하여 다음 단어를 예측 못하게끔 가리고 학습 시키는 방식. 
- 일반 Attension이 모든 단어의 연관 관계를 주목하는것에 반해 Causal Attention은 마스킹을 사용한 Attention방식이다. 
- 계산 식도 attension에서 마스킹만 추가됨

# 결론
1. 결론적으로는 attention_wights 와 values가 내적된 데이터를 반환해야함. 
2. 그러기 위해서 attention_wight 를 casual attention방식으로 계산해야함.
3. casual attention 방식은 masked 방식을 사용함.
	1. Query, key, value를 전부 nn.Linear형태로 만들어서 가중치 계산 준비
	2. dropout을 통하여 과적합을 막음.
	3. torch.triU 를 통하여 윗쪽 삼각형에 1을 마킹함. (나중에 가릴 영역만 표시)
4. 이후 queries와 keys 차원반전값을 내적함. (행렬을 곱하기 위함)
5. 내적한 값이 attention_score 임. 그부분에서 masked =1 인지점을 무한대로 바꿈
6. 그렇게 바꾼 값을 softmax로 씌워주면 끝! (근데 이게 생각보다 외우기가힘듬)

```
import torch

inputs = torch.tensor(
  [[0.43, 0.15, 0.89], # Your     (x^1)
   [0.55, 0.87, 0.66], # journey  (x^2)
   [0.57, 0.85, 0.64], # starts   (x^3)
   [0.22, 0.58, 0.33], # with     (x^4)
   [0.77, 0.25, 0.10], # one      (x^5)
   [0.05, 0.80, 0.55]] # step     (x^6)
)

d_in = inputs.shape[1]   # 입력 차원 (d=3)
d_out = 2                # Q, K, V의 출력 차원 (d=2)

batch = torch.stack((inputs, inputs), dim=0)  ## 3차원으로 만들기 위해 2개입력
# --- 실행 예시 ---
torch.manual_seed(123)

# 가정: batch 변수가 이미 정의되어 있다고 가정 (예: b=2, num_tokens=6, d_in=...)
# context_length는 모델이 허용하는 최대 길이이므로, 현재 배치의 길이와 같거나 더 길게 설정합니다.
context_length = batch.shape[1]  ## 토큰의 갯수를 가져옴 
                                 ## 토큰의 갯수가 context_length 라고 보면됨(총크기)

print("context_length:", context_length)

ca = CausalAttention(d_in, d_out, context_length, 0.0)
context_vecs = ca(batch)

print(context_vecs)
print("context_vecs.shape:", context_vecs.shape)
```
