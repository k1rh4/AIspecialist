RNN - 문맥을 기억하는 메모리의 탄생
장점: 가변길이 처리 (hidden state 가 킬링 포인트 이걸 업데이트한다)
단점: 길수록 잊혀진다. (가장 마지막 정보가 가장 뚜렷하게 남는다)

Hidden state (은닉층을 말하는듯)
앞의 문장을 가지고 다음 단어를 예측하는 것


RNN attention : 앞에 있는것을 참고하면서 번역 정확도 향상.
단점: 메모리 사용 증가. 순차처리만 가능. Hidden에 다른 정보가 섞임

Transformer : 순차적으로 흘러가는 모습을 없애고 병렬화 가능하게 만듬. 
- 병렬화가 되면서 많은 데이터를 학습할 수 있음.
- RNN의 순차 방식을 깨므로써 정확도를 올림.
- 내부적으로 Attention 과 FFN(Feed forword network?) 가 있음.
- Transformer의 핵심은 attention이 병렬 가능한 구조라는 점

인코더와 디코더의 차이가 존재함.
- 인코더는 self-attention을 하고
- 디코더는 임베딩된 데이터를 바탕으로 attension을 하므로 더 방대한 데이터를 참조한다
	- cross attention이라는 용어를 씀 (다른 단어 참고)
- 임베딩 데이터를 attension 하는 거 말고는 인코더랑 디코더랑 똑같음.

# 임베딩
입력값을 쪼개고, 토큰 ID를 발급함. 
ID값을 바탕으로 벡터하나로 표현을 해야함 (N차원 벡터로 표현해야함)
-> 이걸 토큰 임베딩이라고 함. 
-> 임베딩을 하는 방식에 사용하는 N 차원은 사용자 설정임. 
-> 위 예제는 3차원(배열3개짜리)로 만듦
-> 위치 정보에 대한 임베딩이 필요함. 
-> 토큰 임베딩과 위치 임베딩을 만들어서 최종 입력 임베딩을 만듬.
