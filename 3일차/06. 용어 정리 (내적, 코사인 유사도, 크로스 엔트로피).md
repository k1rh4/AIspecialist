# 내적과 유사도의 차이(Inner product Vs Cosine similarity)
![[Pasted image 20261104095052.png]]

inner product(내적) 는 attention이나 학습, classification 에서 정확한 비교값을 필요할때 쓰이고
cosine similarity는 검색, 임베딩 비교 처럼 조회를 할때 쓰인다. 


- Inner Product: 벡터의 크기가 커지면 값도 커져.
- Cosine Similarity: 벡터의 크기가 달라도 방향이 같으면 1이야.
- gradiant(기울기): Gradient는 어떤 값이 변할 때 결과값이 얼마나, 어떤 방향으로 변하는지를 나타낸다는 거야.
- Derivative (미분값, 도함수): 미분값이므로 시각적 정보가 얼마나 빠르게 어떠한 방향으로 변하는지 표현 
	- 밝기가 일정한 영역: 미분값이 0에 가까움
	- 밝기가 급격하게 변하는 영역: 미분값이 큼
	- 밝기가 증가하는 방향: Positive Derivative
	- 밝기가 감소하는 방향: Negative Derivative
- PMF 
	- 이미지가 고양이일 확율을 표현하기 위한 계산 
	- 불확실한 시각적 정보를 정량적인 확률로 바꾸고, 이를 바탕으로 AI가 판단하고 의사결정할 수 있게 해준다는 것이야.
	- Image classification 에서 자주 씀 
- PDF
	- 이미지 속 객체의 위치 좌표가 특정 구간에 있을 확율 
	
![[Pasted image 20261104100648.png]]

- CP (conditional Probability(조건부 확율)
	- 어떤 사건이 발생했다는 사실을 알고 있을 때, 다른 사건이 발생할 확률이 얼마인지를 계산하는 것이야.
	- 예를 들어 다음과 같은 상황을 생각해 보자.
		- A: 이미지에 자동차가 존재한다.
		- B: 이미지에 바퀴가 존재한다
	- 우리가 이미 바퀴가 있다는 사실을 알고 있다면, 자동차가 있을 확률은 바퀴가 있다는 사실을 모를 때와 달라질 수 있어.

# Entropy & Cross entropy
![[Pasted image 20261104101509.png]]
앞에서 배운 확률 개념이 AI의 판단과 추론을 설명한다면
Entropy와 Cross Entropy는 AI가 얼마나 불확실하게 판단하는지, 그리고 예측이 정답과 얼마나 다른지를 측정하는 역할을 해. 이해를 돕기 위해 아래 설명을 보자. 
![[Pasted image 20261104101356.png]]![[Pasted image 20261104101438.png]]
그라디안트와 비슷한 개념이네. 
- 오히려 네가 이해한 방향이 상당히 정확해. Cross Entropy는 Gradient를 계산하기 위한 중요한 출발점이라고 이해하면 좋아.
- Cross Entropy: 모델의 예측이 정답과 얼마나 다른지 측정하는 손실 함수(Loss Function)
- Gradient: 손실을 줄이기 위해 모델의 파라미터를 어느 방향으로 얼마나 변경해야 하는지 알려주는 값


- Cross Entropy: 모델이 정답을 얼마나 잘 맞히도록 학습할 것인가?
	- Cross Entropy는 일반적으로 지도학습에서 사용해.
- KL Divergence: 모델의 확률 분포를 특정한 목표 확률 분포에 얼마나 가깝게 만들 것인가?
	- KL Divergence는 두 확률 분포가 얼마나 다른지를 측정하고, 이를 줄이는 방향으로 모델을 학습시키는 데 활용돼.
