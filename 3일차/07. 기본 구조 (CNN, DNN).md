# softmax vs ReLU
그런데 ReLU와 Softmax는 역할이 완전히 달라.
- ReLU: 신경망이 복잡한 비선형 특징을 학습하도록 도와주는 함수
- Softmax: 여러 출력값을 서로 비교해서 확률 분포로 변환하는 함수

# Backpropagation Vs RNN backword
- Backpropagation(역전파): Loss를 기준으로 Weight의 Gradient를 계산하는 학습 알고리즘
- RNN의 Backward: 문맥에 따라 두 가지 의미가 있어. 양방향 RNN에서 입력 시퀀스를 역방향으로 처리하는 것 또는 RNN 학습 시 시간을 거슬러 역전파하는 것(BPTT)이야.
- 네가 말하는 건 **BPTT(Backpropagation Through Time, 시간 역전파)**야: RNN에서 순방향으로 시퀀스를 처리한 뒤, 마지막 시간 단계부터 처음 시간 단계 방향으로 거슬러 올라가며 Gradient를 계산하는 학습 방식이지.

# CrossEntropyLoss, MSE Loss 언제사용하나?
- CrossEntropyLoss는 강아지 인지 고양이인지 분류하는거고 
- MSELoss는 몸무게가 10kg 인지 가깝게 예측하는거네. 
MSELoss는 숫자를 예측하거나 복원할 때, CrossEntropyLoss는 여러 클래스 중 정답을 분류할 때 주로 사용해.
둘 다 모델의 예측과 정답의 차이를 계산하는 **손실 함수(Loss Function)**지만, 해결하려는 문제와 계산 방식이 달라.

- MSELoss: 연속값 예측 또는 픽셀 복원 → 예측값과 정답의 수치적 차이를 최소화
- CrossEntropyLoss: 여러 클래스 중 하나를 선택하는 분류 → 정답 클래스에 높은 확률을 부여하도록 학습
- BCEWithLogitsLoss: 독립적인 이진 판단 또는 다중 라벨 분류

- CNN에서는 **Kernel(Filter)**이라는 작은 Weight 행렬을 이미지 위에서 이동시키면서 계산해. 예를 들어 3×3 Kernel을 사용하는 경우야.
