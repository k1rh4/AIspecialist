# scaled dot production attention
- QKV를 입력이 들어와서 
- Q * K 내적하고 (내적하기 위해서 transpose... )
- scale 하고   -> Attention 크기 관리  (헤드차원 크기의 제곱근으로 score를 나눈)
	- head 차원이 64라면 attn_score / 8
- mask 하고  -> 지우고 
- softmax 하고 -> 확율 계산하고 
	- dim=-1  # 마지막 차원에 key token별 가중치가 여기 들어가 있음.  
- att결과를 v로 행렬곱을해라.  -> 결과와 비교하여 반영 
#### 위그림만 잘 이해해도 될듯! 


### 입력
 - 긴 문장에서... 특정 단어(token)과 위치를 가져옴. 
 - 임베딩 벡터하나가 튀어나옴
 - 1개의 워드(token)를 D-차원 임베딩으로 표현 
 - positional encoding 도 하고... 두개를 더한다.
 - 더한 값을 Wq, Wk, Wv로 만든다.
