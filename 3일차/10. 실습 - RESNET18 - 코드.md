# 학습 
```
def train_one_epoch(model, loader, optimizer, criterion):
    model.train()  # train mode(dropout/bn 동작 변경)
    total_loss, total_acc = 0.0, 0.0  # 누적 loss/acc
    n = 0  # 샘플 수 누적
    t0 = time.time()  # 시간 측정 시작
    for images, labels in loader:
        images = images.to(device, non_blocking=True)  # 입력을 GPU로 이동 (Asynchronous transfer)
        labels = labels.to(device, non_blocking=True)  # 라벨을 GPU로 이동 (Asynchronous transfer)

        optimizer.zero_grad(set_to_none=True)  # gradient 초기화
        with torch.amp.autocast(device_type=device.type, enabled=torch.cuda.is_available()):  # AMP autocast
            logits = model(images)  # forward
            loss = criterion(logits, labels)  # loss 계산
        scaler.scale(loss).backward()  # scaled backward
        scaler.step(optimizer)  # optimizer step
        scaler.update()  # scaler 업데이트

        bs = images.size(0)  # batch size
        total_loss += loss.item() * bs  # batch loss 누적
        total_acc  += accuracy_top1(logits.detach(), labels) * bs  # logits값만 복사, batch acc 누적
        n += bs  # 샘플 수 누적

    dt = time.time() - t0  # epoch 수행 시간
    return total_loss / n, total_acc / n, dt  # 평균 loss/acc/시간
```

|코드|의미|
|---|---|
|`model.train()`|학습 모드 설정|
|`optimizer.zero_grad()`|이전 기울기 초기화|
|`model(images)`|Forward 실행 및 Logits 계산|
|`criterion(logits, labels)`|Loss 계산|
|`scaler.scale(loss).backward()`|기울기 계산|
|`scaler.step(optimizer)`|Weight 업데이트|
|`scaler.update()`|AMP 스케일 조정|

```
        loss = criterion(logits, labels)  # loss
        bs = images.size(0)  # batch size
        total_loss += loss.item() * bs  # 누적
```

## 1. 평가기준에 따른 출제 가능성

평가기준에는 Vision 분야의 네 가지 항목이 명시되어 있어.

| 평가 영역        | ResNet18 예상 출제 내용                            | 예상 중요도 |
| ------------ | -------------------------------------------- | ------ |
| 모델 원리 이해     | Residual, Conv2d, BatchNorm, Layer 구조        | 매우 높음  |
| 데이터 구성 원리    | CIFAR-10, DataLoader, 배치와 텐서 Shape           | 높음     |
| Library 활용   | torchvision.transforms, torchvision.models   | 매우 높음  |
| 평가 Metric 이해 | CrossEntropyLoss, Accuracy, Confusion Matrix | 높음     |

이 중요도는 공식 출제 비중이 아니라, 평가기준과 실습 코드가 얼마나 직접적으로 연결되는지에 따른 내 추정이야.

## 4. 추가로 공부할 부분

실습 노트북에는 평가기준의 모델 이해·활용 항목과 연결되는 다음 내용도 있어.

- Activation Map: `register_forward_hook()`을 이용한 레이어별 특징 추출
    
- Grad-CAM: Forward/Backward Hook으로 분류 근거 영역 시각화
    
- Confusion Matrix: 클래스별 정확도 및 오분류 분석
    
- Tensor Shape: CIFAR-10 이미지 `(3,32,32)`와 배치 입력 `(B,3,32,32)`, 최종 출력 `(B,10)`
    

이 중 Grad-CAM이나 ONNX 같은 시각화·확장 실습은 기본 모델 구조와 학습 루프를 익힌 다음 공부하는 편이 효율적이야.

결론적으로 ResNet18은 `모델 생성 → CIFAR-10에 맞게 변경 → 데이터 전처리 → 학습 → 평가`의 흐름을 우선 암기하면 돼. Residual의 `out += identity`는 원리 문제로 준비하되, 실습 코드에 없는 구현을 직접 작성하는 문제까지 최우선으로 외울 필요는 없어.




## argumax  는 dim=-1로 외우면됨


```
# ResNet18: [Batch, Classes]
probs = F.softmax(logits, dim=-1)
pred = logits.argmax(dim=-1)

# GPT: [Batch, Tokens, Vocab]
probs = F.softmax(logits, dim=-1)
```
