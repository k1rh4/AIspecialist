```
def forward(self, x):
    identity = x

    out = self.conv1(x)
    out = self.bn1(out)
    out = self.relu(out)

    out = self.conv2(out)
    out = self.bn2(out)

    out = out + identity

    out = self.relu(out)

    return out
```


- BatchNorm2d: 같은 채널의 값을 여러 이미지에 걸쳐 정규화한다.
- LayerNorm: 각 데이터를 독립적으로 정규화한다.
- 
- LayerNorm → **이미지별로** 특징값을 정규화
- BatchNorm2d → 채널별로 묶어 정규화
