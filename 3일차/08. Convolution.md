
# 1x1 convolution
- Kernel 의 크기를 1짜리를 쓰는거임. 
- 커널을 K개를 쓰면 ->  채널이 K개로 바뀜. (이게 핵심) - 채널을 맞추기 위해서도 쓸수 있음.
	- 1x1 이므로 다른 곳에는 영향을 주지 않음. (채널만 변경가능)
	- K개를 안쓰면 K개로 안줄어들어서 늘어날수도 있음. 
- 채널의 깊이가 바뀐다는게 무슨의미인가? 
	- 채널은 이미지 특징의 종류임. 
	- 채널은 일반적으로 RGB 3개의 채널로 구성됨. 
	- 연산량을 줄일수는 있는데.. INPUT FEATURE에 대해서.. input 정보가 줄어든다. 
	- CNN에서 나오는 Feature map을 압축하는 용도이다.

# Transposed Convolution
- 해상도 복구 모드 (이게 가능하구나)
- Transposed Convolution(전치 합성곱)은 CNN에서 줄어든 Feature Map의 가로·세로 크기를 다시 늘릴 때 사용하는 연산이야.

# Linear Layer 의 의미 
`Linear Layer`는 입력된 여러 숫자(Feature)에 각각 Weight를 곱하고, 그 결과를 더해서 새로운 Feature를 만드는 Layer야.
주요 목적은 기존 Feature를 학습된 Weight로 조합해서 새로운 Feature로 변환하는 것이야.
- `x`: 입력 Feature
- `W`: 학습 가능한 Weight
- `b`: 학습 가능한 Bias
- `y`: 새롭게 계산된 출력 Feature

### Linear 와 Conv2d 의 차이 
![[Pasted image 20261104132558.png]]


- Weight(Kernel): 학습하면서 값이 바뀌는 것
- Feature Map: 학습된 Weight를 입력 데이터에 적용해서 만들어지는 것
- Channel: 그 Feature Map들을 구분하는 축
