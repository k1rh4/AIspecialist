# Linear Regression
### ① Feature Engineering (특징 설계)

교안 30페이지에서는 선형 회귀에 사용할 수 있는 Feature를 5가지로 구분해.
- External Attributes: 날씨, 요일 등의 외부 정보
- Lagged Values: 어제, 그제의 주가 등 과거 값
- Trend Features: 어제와 그제의 주가 차이 등 추세
- Seasonal Features: 지난주 같은 요일의 매출 등 계절성
- Average Features: 최근 7일간 평균 매출 등 평균값

어떤 feature 를 사용하는지에 따라 결과가 달라질 수 있음.
