## 1. Time Series — 시계열 예측

**파일:** `ts_practice.ipynb`, `ts_solution.ipynb`

### 1-1. sklearn import

```python
from sklearn.preprocessing import MinMaxScaler
from sklearn.metrics \
import mean_squared_error, mean_absolute_percentage_error
```

### 1-2. MinMaxScaler — 데이터 스케일링

```python
# Scaling dataset
scaler = MinMaxScaler(feature_range=(0, 1))
train_scaled = scaler.fit_transform(train_data.values)
test_scaled = scaler.transform(test_data.values)
```

- `feature_range=(0, 1)`: 스케일링 목표 범위를 0~1로 설정.
- `fit_transform(...)`: 훈련 데이터로 스케일 기준을 구하고 변환.
- `transform(...)`: 훈련 데이터에서 구한 기준으로 테스트 데이터 변환.

### 1-3. mean_squared_error / mean_absolute_percentage_error — 모델 평가

**연습 파일(`ts_practice.ipynb`)에 실제로 있는 TODO:**

```python

```

```python
rmse = np.sqrt(mean_squared_error(y_test, test_predictions))
```

- `mean_squared_error(정답, 예측)`: 실제 값과 예측 값의 평균제곱오차(MSE).
- `np.sqrt(...)`: MSE의 제곱근을 구하여 RMSE 계산.
- `mean_absolute_percentage_error(정답, 예측)`: 평균절대백분율오차(MAPE). 반환값은 기본적으로 퍼센트 표시(예: 10)가 아닌 비율(예: 0.1)입니다.
- 두 함수의 **첫 번째 인수는 정답 `y_test`**, **두 번째 인수는 예측 `test_predictions`**입니다.

> `ts_practice.ipynb`의 다른 평가 함수(`test_`)에도 위 완성식이 이미 적혀 있습니다. 실제 TODO는 앞의 평가 함수에 있습니다.

## 2. GCF / NGCF — 그래프 추천 시스템

**파일:** `RecSys_GCF_practice.ipynb`, `RecSys_GCF_sol.ipynb`

### 2-1. sklearn import

```python
from sklearn.model_selection import train_test_split
```

### 2-2. train_test_split — 엣지 분할

```python
# Split indices into train/val/test set (label for train/val/test set)
train_indices, test_indices = train_test_split(range(edge_index.size(1)), test_size=0.2)
val_indices, test_indices = train_test_split(test_indices, test_size=0.5)

train_edge_index = edge_index[:, train_indices]
val_edge_index = edge_index[:, val_indices]
test_edge_index = edge_index[:, test_indices]
```

- 첫 호출: 인덱스를 학습 80%, 나머지 20%로 분리.
- 두 번째 호출: 나머지 20%를 검증/테스트로 반씩 분리 → 결과적으로 **학습 80%, 검증 10%, 테스트 10%**.
- `edge_index.size(1)`: 엣지 인덱스 텐서의 두 번째 축 길이(엣지 수).
- 이 구간은 `practice` 파일에서 별도의 빈칸 문제가 아닙니다.

## 3. NCF — 신경망 협업 필터링

**파일:** `RecSys_NCF.ipynb`

### 3-1. sklearn import

```python
from sklearn import model_selection, metrics, preprocessing
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error
```

> `metrics`와 직접 import한 `train_test_split`도 import되지만, 아래 실제 분할 호출은 `model_selection.train_test_split(...)` 형태입니다.

### 3-2. LabelEncoder — 사용자/영화 ID 변환

```python
# convert actual index for user and items as consecutive integer
lbl_user = preprocessing.LabelEncoder()
lbl_movie = preprocessing.LabelEncoder()

df.userId = lbl_user.fit_transform(df.userId.values)
df.movieId = lbl_movie.fit_transform(df.movieId.values)
```

- 사용자 ID, 영화 ID를 각각 독립적으로 정수 인코딩.
- `fit_transform(...)`은 데이터의 범주를 학습해 연속 정수 ID로 변환.

### 3-3. train_test_split — 평점 데이터 분할

```python
# devide original dataframe into train, test dataframe (9:1)
df_train, df_test = model_selection.train_test_split(df, test_size=0.1, random_state=42, stratify=df.rating.values)
```

- `test_size=0.1`: 훈련 90%, 테스트 10%.
- `random_state=42`: 재현 가능한 분할을 위한 난수 시드.
- `stratify=df.rating.values`: 평점의 분포를 고려해 층화 분할.

### 3-4. mean_squared_error — 예측 평점 오차 평가

```python
mse = mean_squared_error(target_rating_list, model_output_list)
rms = np.sqrt(mse)
print(f"rms: {rms}")
```

- `target_rating_list`: 실제 평점.
- `model_output_list`: 모델이 예측한 평점.
- `mse`: 평균제곱오차.
- `rms`: MSE에 제곱근을 적용한 값(일반적으로 RMSE라고 부름).

## 시험 대비 암기 포인트

1. **실제 TODO 출제 구간:** Time Series의 두 평가식 인수 `(y_test, test_predictions)`.
2. `mean_squared_error`는 **MSE**, `np.sqrt(mean_squared_error(...))`는 **RMSE**.
3. `MinMaxScaler`에서는 훈련 데이터에 `fit_transform`, 테스트 데이터에 `transform`.
4. `train_test_split`은 GCF에서 **80/10/10**, NCF에서 **90/10** 분할에 사용.
5. `LabelEncoder`는 NCF에서 사용자/영화 ID 각각에 따로 적용.
