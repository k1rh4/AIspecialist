DETR은 Transformer를 이용해서 이미지 속 객체의 위치와 종류를 동시에 찾아내는 Object Detection 모델이야.

① CNN Backbone: ResNet 같은 CNN으로 이미지의 특징(Feature)을 추출해. 앞에서 배운 Conv2d가 여기서 활용되는 거지.
② Transformer Encoder:  추출된 특징들을 Self-Attention으로 처리해서 이미지의 서로 다른 영역 간 관계를 학습해.
③ Transformer Decoder : 학습 가능한 Object Query를 사용해 이미지 특징을 참조하고, 객체별 종류와 위치를 예측해.

여기까지는 이전에 공부했던 GPT의 Attention과도 연결되는 내용이야.
DETR = CNN + Transformer + Object Query + Hungarian Matching
