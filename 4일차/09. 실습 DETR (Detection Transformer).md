Detection Transformer == 논문 제목에 의미가 다담겨있음.  RESNET (CNN기반 탐지) 
DETR은 Transformer를 이용해서 이미지 속 객체의 위치와 종류를 동시에 찾아내는 Object Detection 모델이야.
![[Pasted image 20261106084241.png]]
ViT = Patch Embedding + Transformer Encoder + Classification Head
DETR = CNN Backbone + Transformer Encoder/Decoder + Detection Head



1. CNN Backbone: ResNet 같은 CNN으로 이미지의 특징(Feature)을 추출해. 앞에서 배운 Conv2d가 여기서 활용되는 거지.**
2.  Transformer Encoder:  추출된 특징들을 Self-Attention으로 처리해서 이미지의 서로 다른 영역 간 관계를 학습해.**
3. Transformer Decoder : 학습 가능한 Object Query를 사용해 이미지 특징을 참조하고, 객체별 종류와 위치를 예측해.**
4. **Detection Heads (Class Head, Box Head)**
5. **후처리 (Softmax, 필터링, 좌표 복원)**

**위 5단계가 큰 흐름.** 

흐름
1. Input Image > Backbone (ResNet50) 호출 > Transformer Ecoder > Trasnformer Decoder > Prediction Head 
	- 이미지 > 백본 > 인코더 > 디코더 > 예측 
		- 이미지 전처리 (trasnform, tensor, nomalize)   = (I)
		- 모델로드 (torch.hub.load(), eval())                = (B)
		- DETR 추론 (output = model(img))               = (M)
		- 클래스확률 계산 (softmax(-1))                    = (TE)
		- 객체 필터링 (max(-1).vale() > 0.9)
		- Bounding Box 좌표 복원(rescale_bboxes())
		- 탐지 결과 출력 (plot_results()

## 1. 전체 단계별 함수 순서

| 단계                | 역할                         | 주요 함수·연산 순서                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ----------------- | -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| I — Input         | 이미지 입력 및 전처리               | ① `Image.open()` → ② `transform(im)` → ③ `Resize(800)` → ④ `ToTensor()` → ⑤ `Normalize()` → ⑥ `unsqueeze(0)`                                                                                                                                                                                                                                                                                                                       |
| B — Backbone      | ResNet50 특징 추출             | ① `model(img)` → ② `nested_tensor_from_tensor_list()` → ③ `self.backbone()` → ④ `self[0]()` → ⑤ `self.body()` → ⑥ `F.interpolate()` → ⑦ `NestedTensor()` → ⑧ `self[1]()` → ⑨ `.to()`                                                                                                                                                                                                                                               |
| M — Map           | 특징맵을 Transformer 입력 형태로 변경 | ① `features[-1]` → ② `decompose()` → ③ `self.input_proj()` → ④ `src.shape` → ⑤ `src.flatten(2)` → ⑥ `permute(2,0,1)` → ⑦ `pos_embed.flatten(2)` → ⑧ `permute(2,0,1)` → ⑨ `query_embed.unsqueeze(1)` → ⑩ `repeat()` → ⑪ `mask.flatten(1)` → ⑫ `torch.zeros_like()`                                                                                                                                                                  |
| T-E — Encoder     | 이미지 특징 분석                  | ① `self.encoder()` → ② `layer()` → ③ `forward_post()` → ④ `with_pos_embed()` → ⑤ `self.self_attn()` → ⑥ `dropout1()` → ⑦ Residual `+` → ⑧ `norm1()` → ⑨ `linear1()` → ⑩ `activation()` → ⑪ `dropout()` → ⑫ `linear2()` → ⑬ `dropout2()` → ⑭ Residual `+` → ⑮ `norm2()`                                                                                                                                                             |
| T-D — Decoder     | Object Query 기반 객체 특징 생성   | ① `self.decoder()` → ② `layer()` → ③ `forward_post()` → ④ `with_pos_embed(tgt, query_pos)` → ⑤ `self.self_attn()` → ⑥ `dropout1()` → ⑦ Residual `+` → ⑧ `norm1()` → ⑨ `with_pos_embed(tgt, query_pos)` → ⑩ `with_pos_embed(memory, pos)` → ⑪ `multihead_attn()` → ⑫ `dropout2()` → ⑬ Residual `+` → ⑭ `norm2()` → ⑮ `linear1()` → ⑯ `activation()` → ⑰ `dropout()` → ⑱ `linear2()` → ⑲ `dropout3()` → ⑳ Residual `+` → ㉑ `norm3()` |
| P — Prediction    | 클래스 및 좌표 예측                | ① `hs.transpose(1,2)` → ② `self.class_embed(hs)` → ③ `self.bbox_embed(hs)` → ④ `sigmoid()` → ⑤ `outputs_class[-1]` → ⑥ `outputs_coord[-1]` → ⑦ `pred_logits` / `pred_boxes`                                                                                                                                                                                                                                                        |
| S — Softmax       | 클래스별 확률 변환                 | ① `outputs['pred_logits']` → ② `softmax(-1)` → ③ `[0, :, :-1]`                                                                                                                                                                                                                                                                                                                                                                     |
| C — Confidence    | 높은 신뢰도 객체 선택               | ① `probas.max(-1)` → ② `.values` → ③ `> 0.9` → ④ `keep`                                                                                                                                                                                                                                                                                                                                                                            |
| R — Rescale       | Bounding Box 변환            | ① `rescale_bboxes()` → ② `box_cxcywh_to_xyxy()` → ③ `unbind(1)` → ④ 좌표별 `± 0.5*w/h` → ⑤ `torch.stack()` → ⑥ `torch.tensor()` → ⑦ 좌표에 이미지 크기 곱하기 → ⑧ `return b`                                                                                                                                                                                                                                                                     |
| V — Visualization | 결과 이미지 출력                  | ① `plot_results()` → ② `plt.subplots()` → ③ `ax.imshow()` → ④ `COLORS * 100` → ⑤ `boxes.tolist()` → ⑥ `zip()` → ⑦ `plt.Rectangle()` → ⑧ `ax.add_patch()` → ⑨ `p.argmax()` → ⑩ 클래스 텍스트 생성 → ⑪ `ax.text()` → ⑫ `ax.axis()` → ⑬ `fig.tight_layout()`                                                                                                                                                                                  |

DERT만의 특징 Forward Hook
```
conv_features, enc_attn_weights, dec_attn_weights = [], [], []

hooks = [
    model.backbone[-2].register_forward_hook(                                  ## CNN 특징맵
        lambda self, input, output: conv_features.append(output)
    ),
    model.transformer.encoder.layers[-1].self_attn.register_forward_hook(      ## Encoder Self-Attention

    ),
    model.transformer.decoder.layers[-1].multihead_attn.register_forward_hook(   ## Decoder Cross-Attention

    ),
]

    hook.remove()
```



trasformer_encode 나 trasnformer_decode는 model 에서 RESNET50 을 가져올때 가져온다.
```
# [DETR] 내부 텐서(특징맵/어텐션) 추출을 위한 forward hook
# - 논문 분석 포인트:
#   1) backbone CNN 특징맵(conv_features)
#   2) 마지막 encoder layer의 self-attention(enc_attn_weights)
#   3) 마지막 decoder layer의 cross-attention(dec_attn_weights)
# - PyTorch hook을 등록해 forward 중간 결과를 캡처합니다.

# use lists to store the outputs via up-values
conv_features, enc_attn_weights, dec_attn_weights = [], [], []  # hook 결과를 담을 리스트(클로저 변수) 초기화

hooks = [  # 각 모듈에 forward hook 등록
    model.backbone[-2].register_forward_hook(  # CNN backbone의 특정 stage 출력(feature map) 저장
        lambda self, input, output: conv_features.append(output) # lambda 인자들 : 실행문
    ),
    model.transformer.encoder.layers[-1].self_attn.register_forward_hook(  # encoder self-attention의 attention weights(output[1]) 저장
        lambda self, input, output: enc_attn_weights.append(output[1])   # self-attention weight -> output[1]
    ),
    model.transformer.decoder.layers[-1].multihead_attn.register_forward_hook(  # decoder cross-attention의 attention weights(output[1]) 저장
        lambda self, input, output: dec_attn_weights.append(output[1])   # cross-attention weight -> output[1]
    ),
]

# propagate through the model
outputs = model(img)  # hook이 등록된 상태로 forward 실행

for hook in hooks:  # 등록했던 hook 해제(메모리/부작용 방지)
    hook.remove()

# don't need the list anymore
conv_features = conv_features[0]  # hook 결과를 담을 리스트(클로저 변수) 초기화
print(f"features shape: {conv_features['0'].tensors.shape}")   # [1, channels, H, W]
enc_attn_weights = enc_attn_weights[0]  # encoder attention weights 텐서
print(f"enc_attn_weights shape: {enc_attn_weights.shape}")   # [1, HW, HW] -> 각 feature간 attention
dec_attn_weights = dec_attn_weights[0]  # decoder attention weights 텐서
print(f"dec_attn_weights shape: {dec_attn_weights.shape}")   # [1, N, HW] -> 각 객체와 feature간 attention
```

그런데 PyTorch의 Hook은 직접 호출하지 않아. `register_forward_hook()`으로 등록하면 모델 실행 시 자동 호출되는 구조야.




bounding box 좌표 변환 코드
 - 중심 좌표를 꼭지점으로 옮긴다. 
```
def box_cxcywh_to_xyxy(x):

    x_c, y_c, w, h = x.unbind(1)   ## 각 객체의 좌표 4개를 분리
    
    # 중심 좌표를 사각형 양 끝 좌표로 변경
    b = [
        (x_c - 0.5 * w),  # xmin: 중심 X - 너비 절반
        (y_c - 0.5 * h),  # ymin: 중심 Y - 높이 절반
        (x_c + 0.5 * w),  # xmax: 중심 X + 너비 절반
        (y_c + 0.5 * h)   # ymax: 중심 Y + 높이 절반
    ]

    return torch.stack(b, dim=1)   ## 변환된 좌표 4개를 다시 결합

def rescale_bboxes(out_bbox, size):   ## 원본이미지의 픽셀 좌표 변환 
    img_w, img_h = size

    b = box_cxcywh_to_xyxy(out_bbox)    ## 좌표 표현 방식 변경 

    b = b * torch.tensor(
        [img_w, img_h, img_w, img_h],
        dtype=torch.float32
    )

    return b
```


rescale_bboxes   - 후처리 코드 
- 내부에서 box_cxcywh_to_xyxy 를 호출한다.  
```
def rescale_bboxes(out_bbox, size):

    # ① 원본 이미지 크기 가져오기
    # size = (width, height)
    img_w, img_h = size

    # ② 중심 좌표를 꼭짓점 좌표로 변환
    # (cx, cy, w, h) → (xmin, ymin, xmax, ymax)
    b = box_cxcywh_to_xyxy(out_bbox)

    # ③ 정규화된 좌표(0~1)를 실제 픽셀 좌표로 변환
    # X좌표에는 이미지 너비를 곱하고
    # Y좌표에는 이미지 높이를 곱함
    b = b * torch.tensor(
        [img_w, img_h, img_w, img_h],
        dtype=torch.float32
    )

    # ④ 변환된 Bounding Box 반환
    return b
```

모델에는 Backbone, Transformer Encoder, Transformer Decoder, Object Query, Detection Head가 포함되어 있다.

- Backbone: 이미지 특징 추출
    
- Encoder: 이미지 특징 사이 Self-Attention
    
- Decoder: Object Query를 활용한 Self-Attention과 Cross-Attention
    
- Detection Head: 클래스 점수와 Bounding Box 예측
    
- `eval()` 자체는 Gradient 계산을 비활성화하지 않는다.

## 6. 클래스 확률 계산

```
probas = outputs['pred_logits'].softmax(-1)[0, :, :-1]
```

- `pred_logits`: 클래스 점수
    
- `softmax(-1)`: 마지막 클래스 차원의 점수를 확률로 변환
    
- `[0]`: 첫 번째 이미지
    
- `:`: 전체 Object Query
    
- `:-1`: 마지막 No Object 클래스 제외
    

**Shape 변화:** `[1,100,92]` → `[100,91]`

## 7. 신뢰도 필터링

```
keep = probas.max(-1).values > 0.9
```

- `max(-1)`: 각 Query에서 가장 높은 클래스 확률 검색
    
- `.values`: 최대 확률값
    
- `> 0.9`: 신뢰도 90% 초과 객체 선택
    
- `keep`: Boolean Tensor
    

예시:

```

# 필터링 결과

```

## 8. Bounding Box 좌표 변환

DETR은 `(cx, cy, w, h)` 형태의 정규화된 좌표를 반환한다.

### 8-1. 중심 좌표 → 꼭짓점 좌표

```
def box_cxcywh_to_xyxy(x):
    # 중심 좌표, 너비, 높이 분리
    x_c, y_c, w, h = x.unbind(1)

    # 양쪽 꼭짓점 좌표 계산
    b = [
        (x_c - 0.5 * w),  # xmin
        (y_c - 0.5 * h),  # ymin
        (x_c + 0.5 * w),  # xmax
        (y_c + 0.5 * h)   # ymax
    ]

    return torch.stack(b, dim=1)
```

`unbind(1)`은 좌표 네 개를 분리하고, `torch.stack(dim=1)`은 다시 결합한다.

### 8-2. 실제 픽셀 좌표로 복원

```
def rescale_bboxes(out_bbox, size):
    # 이미지 원본 너비, 높이
    img_w, img_h = size

    # 중심 좌표 → 꼭짓점 좌표
    b = box_cxcywh_to_xyxy(out_bbox)

    # 정규화된 좌표를 픽셀 좌표로 변환
    b = b * torch.tensor(
        [img_w, img_h, img_w, img_h],
        dtype=torch.float32
    )

    return b
```

### 8-3. 호출 부분

```
bboxes_scaled = rescale_bboxes(
    outputs['pred_boxes'][0, keep],
    im.size
)
```

**암기:** 중심 좌표 → 꼭짓점 좌표 → 픽셀 좌표

## 10. Forward Hook으로 내부 Attention 추출

Hook은 특정 레이어의 실행 결과를 저장하는 콜백 기능이다.

```
# 결과 저장 리스트
conv_features, enc_attn_weights, dec_attn_weights = [], [], []

# Hook 등록
hooks = [
    # Backbone Feature Map 저장
    model.backbone[-2].register_forward_hook(
        lambda self, input, output: conv_features.append(output)
    ),

    # Encoder 마지막 Self-Attention 저장
    model.transformer.encoder.layers[-1].self_attn.register_forward_hook(
        lambda self, input, output: enc_attn_weights.append(output[1])
    ),

    # Decoder 마지막 Cross-Attention 저장
    model.transformer.decoder.layers[-1].multihead_attn.register_forward_hook(
        lambda self, input, output: dec_attn_weights.append(output[1])
    ),
]

# 모델 실행 → Hook 자동 호출
outputs = model(img)

# Hook 제거
for hook in hooks:
    hook.remove()

# 결과 가져오기
conv_features = conv_features[0]
enc_attn_weights = enc_attn_weights[0]
dec_attn_weights = dec_attn_weights[0]
```

### Hook별 역할

|위치|저장 데이터|
|---|---|
|`model.backbone[-2]`|CNN 특징맵|
|`encoder.layers[-1].self_attn`|Encoder Self-Attention Weight|
|`decoder.layers[-1].multihead_attn`|Decoder Cross-Attention Weight|

`register_forward_hook()`으로 등록하면 `model(img)` 실행 중 해당 모듈의 Forward가 끝날 때 PyTorch가 콜백을 자동 실행한다.

`output[1]`은 `nn.MultiheadAttention` 반환값의 두 번째 요소인 Attention Weight다.

**암기:** Hook 등록 → 모델 실행 → 자동 저장 → Hook 제거

## 11. Attention 결과 시각화

```
# Backbone 특징맵의 가로세로 크기
h, w = conv_features['0'].tensors.shape[-2:]

# Decoder Cross-Attention을 공간 형태로 변환
dec_attn_weights[0, idx].view(h, w)

# Encoder Attention 변환
f_map = conv_features['0']
shape = f_map.tensors.shape[-2:]

sattn = enc_attn_weights[0].reshape(shape + shape)
```

- Encoder Self-Attention: 이미지 위치별 특징들 사이의 관계
    
- Decoder Cross-Attention: 각 Object Query가 이미지의 어느 위치에 주목하는지 확인
