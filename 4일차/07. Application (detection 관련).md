# IoU (Intersection over Union)
- Ground truth 영역과, 모델의 결과의 교집합을 분자로 보내고, 합집합을 분모로 보내서 비율을 계산한다. 
- 완벽히 두개가 일치하면 1이 된다.
- 찾았다 못찾았다는 IoU 값으로한다.

Recall= FN이 0으로 수렴해야 1이 된다. 
- Precision (정밀도): 내가 찾은 것 중에 정답이 얼마나 있나?
- Recall (재현율): 실제 정답 중에 내가 얼마나 찾아냈나?
- Precision = 정확하게 찾았나?
- Recall = 빠짐없이 찾았나?
	- 암환자 탐지 (이게중요)

F1 은 recall과 precision이 둘다 잘나와야 높은 수치이다. 
- 모든것을 탐지했다고 하면 recall은 올라가지만 precision이 줄어든다.


AP와 MAP는 앞에서 배운 Precision과 Recall을 기반으로 검색 결과의 순위까지 평가하는 지표야.
특히 RAG나 검색 시스템에서 중요해.

- AP (Average Precision): 하나의 질문에 대해 관련 문서를 얼마나 상위에 잘 배치했는가?
- MAP (Mean Average Precision): 여러 질문의 AP를 평균 낸 값.

### Fast- R-CNN
Fast R-CNN은 이미지에서 객체가 어디에 있고, 무엇인지를 찾아내는 객체 탐지(Object Detection) 모델이야.
핵심은 이미지 전체에 Conv를 한 번 수행하고, 그 결과인 Feature Map을 여러 객체 후보 영역에서 재사용한다는 거야.
