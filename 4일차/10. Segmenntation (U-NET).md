# Segmentation (이미지 분할)

Segmentation은 이미지의 각 픽셀(Pixel)이 무엇에 해당하는지 분류하는 기술이야.
U-Net은 객체의 정확한 모양과 경계선을 찾아내는 Segmentation(영상 분할) 에 특화된 모델이야.
특히 의료영상에서 장기, 종양, 암세포 등의 영역을 픽셀 단위로 구분하는 데 강점이 있어.

암세포의 모양을 학습할수 있을까?

크게 3가지 구조로 되어 있고, 
1. Contracting path
	1. 일반적인 CNN 구조인데 대각선 아래로 내려와짐
	2. 이미지사이즈는 줄이고, 채널수를 늘린다
	3. 의료영상 이미지는 gray scale (흑백 사진)이므로 채널이 1장으로 시작함.
	4. 파란색 화살표는 3x3 conv -> ReLU 
	5. 패딩을 안해서 사이즈가 줄었다. 
	6. 컨벌류션 커널을 64 채널을씀
	7. 2-byte max pooling을함.  (사이즈를 반으로 줄임)
	8. 
2. Skip connection
	1. 자르고 붙인다. 
	2. 해상도를 늘린다. 
3. Expanding path
	1. 이미지 사이즈는 늘리고 채널을 줄인다. 
	2. 정확도를 올리는 목표
	3. 해상도가 줄어들어서, Contracting path에서 시작한 이미지를 가져다 붙있다 (concat)
		1. why? -> 위치정보를 가져오기 위함. 
		2. 일종의 전차연산같은느낌인가...

패딩을 굳이 하지 않는 이유는.. 의료 영상은 패딩으로 인한 왜곡을 하면 안되기 때문이다. 
-> 정확도를 올리고 크기를 줄였다. 



Contracting은 무엇이 있는지(특징) 를 파악하고, 
Skip Connection은 어디에 있었는지(공간적 위치 정보) 를 전달하고, 
Expanding은 이 둘을 결합해서 어느 픽셀이 대상인지 예측하는 구조야.

맞아. U-Net은 줄였다가(Encoder), 다시 키우는(Decoder) U자형 구조야.

다만 한 가지 정확히 이해해야 할 부분은 Skip Connection이 Encoder와 Decoder 사이에 별도의 단계로 존재하는 게 아니라, 두 부분을 가로로 연결한다는 거야.
```
         Encoder                Decoder
         (Down)                  (Up)

       x1 ────── Skip ─────────→ up4
        ↓                         ↑
       x2 ────── Skip ─────→ up3  │
        ↓                    ↑    │
       x3 ────── Skip ─→ up2 │    │
        ↓               ↑    │    │
       x4 ── Skip ─→ up1     │    │
        ↓            ↑
       x5 ───────────┘
       (Bottleneck)
```
