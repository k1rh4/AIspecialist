- shifted window (window를 이동시켜 서로다른 영역 정보도 중첩된 부분 정보를 교환한다.)
- cyclic shift (순환 이동) : 짜투리 window 를 짤라서 다른곳에 붙이는 작업

# DNIO
- DINO는 정답 라벨 없이 이미지 자체만으로 특징(Feature)을 학습하는 자기지도학습(Self-Supervised Learning) 모델이야.![[Pasted image 20261105095101.png]]
- Teacher 와 Stuent를 구분해 줘서 학습하는게 핵심인데.
![[Pasted image 20261105095357.png]]
- 선생님은 글로벌 뷰만 보여주고, 학생뷰는 근접샷을 보여준다. 
- Teacher가 Labels(정답지)가 된다. 

#### Teacher와 Student는 어떻게 구분할까?
student = VisionTransformer()
teacher = VisionTransformer()
teacher.load_state_dict(student.state_dict()) # Teacher에 Student의 초기 가중치 복사
- 이후 학습을 하면서 student에서 얻은 결과를 조금씩 선생님한테 넘긴다. 
위 그림에서 선생님 위에 centering 을 두어서 학생과 똑같은 아웃풋을 막는다.

- loss = p2LOGp1 인데, p2는 정답, p1는 대입값. 
- cross entropy와 비슷하다. 
- Teacher가 처음부터 정확한 의미를 알고 있을 필요는 없어. 다양한 이미지에서 일관된 표현을 학습하는 과정에서 유용한 특징이 형성될 수 있는 거지.
