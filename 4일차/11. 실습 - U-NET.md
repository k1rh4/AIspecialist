## 1. U-Net 전체 흐름 (핵심 6단계)
```
### 1. Contracting Path = SCM
- S — Shrink: MaxPool로 이미지 가로·세로 절반 축소
- C — Conv: 3×3 Conv로 특징 추출
- M — More channels: 내려갈수록 채널 수 증가

암기: 크기는 줄이고(S), 특징을 추출하고(C), 채널은 늘린다(M).

### 2. Skip Connection = CC
- C — Copy: Encoder의 특징맵을 가져옴
- C — Concat: Decoder의 특징맵과 채널 방향으로 결합
    
암기: Copy & Concat = 위치 정보를 살린다.

### 3. Expanding Path = CUL
- C — Concat: Encoder 특징과 결합
- U — Upsampling: 이미지 해상도 확대
- L — Less channels: 채널 수 감소
  
  암기: 합치고(C), 키우고(U), 채널을 줄인다(L).
```

# U-NET class
```
class UNet(nn.Module):
    def __init__(self, n_channels, n_classes, bilinear=False):
        super().__init__()

        # Encoder 구성
        self.inc = DoubleConv(n_channels, 64)   
        self.down1 = Down(64, 128)
        self.down2 = Down(128, 256)
        self.down3 = Down(256, 512)

        factor = 2 if bilinear else 1  ## blidnear 가 False 이면 1
        
        self.down4 = Down(512, 1024 // factor) ## 이게 말했던 bootle nect처리구나 
        

        # Decoder
        self.up1 = Up(1024, 512 // factor, bilinear)
        self.up2 = Up(512, 256 // factor, bilinear)
        self.up3 = Up(256, 128 // factor, bilinear)
        self.up4 = Up(128, 64, bilinear)

        # Output Head
        self.outc = OutConv(64, n_classes)

    def forward(self, x):
        # Encoder
        x1 = self.inc(x)    ## 일반 Double Conv2d 시작. 
        x2 = self.down1(x1)   ## maxPool -> Double Conv2d 
        x3 = self.down2(x2)   ## maxPool -> Double Conv2d 
        x4 = self.down3(x3)
        x5 = self.down4(x4)

        # Decoder + Skip Connection
        x = self.up1(x5, x4)   ## Transpose -> padding -> skip connection 
        x = self.up2(x, x3)
        x = self.up3(x, x2)
        x = self.up4(x, x1)    ## 

        # Output
        logits = self.outc(x)  ## 1x1Conv를 이용하여 채널 조절
        return logits
```

```
class DoubleConv(nn.Module):   ## conv2d를 2번해서 doubleCov 
    def __init__(self, in_channels: int,
                 out_channels: int,
                 mid_channels: int | None = None):
        super().__init__()

        if mid_channels is None:
            mid_channels = out_channels

        self.net = nn.Sequential(
            nn.Conv2d(in_channels, mid_channels,
                      kernel_size=3, padding=1, bias=False),
            nn.ReLU(inplace=True),

            nn.Conv2d(mid_channels, out_channels,
                      kernel_size=3, padding=1, bias=False),
            nn.ReLU(inplace=True),
        )

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        return self.net(x)
```
핵심 흐름: Conv → ReLU → Conv → ReLU   (2번해서 double Conv 라고 하는구나 ㅋㅋ )
- `kernel_size=3`: 3×3 커널로 특징 추출
- `padding=1`: 이미지 가로·세로 크기 유지
- `mid_channels`: 첫 Conv의 출력 채널
- `out_channels`: 최종 출력 채널

# Up classs
Upsampling + Skip Connection + DoubleConv를 수행해.
Upsampling → Padding → Concat → DoubleConv (UPCD로 외우면됨)
참고로 실습의 기본 설정은 `bilinear=False`이므로 `nn.Upsample`이 아니라 `nn.ConvTranspose2d` 경로를 사용해.

```
class Up(nn.Module):
    def __init__(self, in_channels, out_channels, bilinear=False):
        super().__init__()

        if bilinear:
            self.up = nn.Upsample(
                scale_factor=2,
                mode="bilinear",
                align_corners=True
            )
            self.conv = DoubleConv(
                in_channels, out_channels,
                mid_channels=in_channels // 2
            )
        else:
            self.up = nn.ConvTranspose2d(
                in_channels,
                in_channels // 2,
                kernel_size=2,
                stride=2
            )
            self.conv = DoubleConv(in_channels, out_channels)

    def forward(self, x1: torch.Tensor, x2: torch.Tensor) -> torch.Tensor:

        # 1. Upsampling
        x1 = self.up(x1)

        # 2. 크기 차이 계산
        diff_y = x2.size(2) - x1.size(2)
        diff_x = x2.size(3) - x1.size(3)

        # 3. Padding으로 크기 정렬
        x1 = F.pad(x1, [
            diff_x // 2,
            diff_x - diff_x // 2,
            diff_y // 2,
            diff_y - diff_y // 2
        ])

        # 4. Skip Connection (Concat)
        x = torch.cat([x2, x1], dim=1)

        # 5. DoubleConv
        return self.conv(x)
```
