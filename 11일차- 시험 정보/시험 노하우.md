- 옵티마이저 - adam 잡고 
- 학습 시작.  (SPAM train_classifier_simple 트레이닝을씀. )
- 끝. 

- LORA는 모델의파라미터 고정 부분과
- Layer를 적층할때 A는 랜덤값으로 B는 0으로 초기화 하는게 킬포인트
- ```python

  class LoRALayer(nn.Module):
    def __init__(self, in_dim, out_dim, rank, alpha):
        """
        LoRA(Low-Rank Adaptation) 레이어 초기화
        """

        super().__init__()
        self.A = nn.Parameter(torch.empty(in_dim, rank))
        nn.init.kaiming_uniform_(self.A, a=math.sqrt(5))
        self.B = nn.Parameter(torch.zeros(rank, out_dim))
        self.alpha = alpha
        self.rank = rank
        
     def forward(self, x):
        # region [LoRA 어댑터 적용]
        x = (self.alpha / self.rank) * (x @ self.A @ self.B)
        return x       
        
  ```

# RAG-1
## 시험 직전 체크

- `documents`는 문서를 담은 컬렉션이고, `nodes`는 문서에서 분할된 청크다.
- `VectorStoreIndex.from_documents(...)`는 문서를 인덱싱한다. 기본 설정에서는 임베딩 API 호출이 필요할 수 있다.
- `index.as_retriever()`는 검색기를, `index.as_query_engine()`은 검색과 응답 합성까지 가능한 질의 엔진을 구성한다.
- `retriever.retrieve(question)`는 노드를 검색하고, `query_engine.query(question)`은 답변을 생성한다.
- `get_response_synthesizer(...)`는 합성기를 생성하는 것이며, 실제 사용 여부는 이를 다른 객체에 전달하거나 `synthesize(...)`로 호출하는 흐름을 봐야 한다.
- `insert`, `update_ref_doc`, `refresh_ref_docs`, `delete_ref_doc`의 구별과 전달 인자를 외운다.
- 노트북 코드는 위에서 아래로 실행된다고 가정한다. 동일 변수의 재할당이 있으므로 순서를 확인한다.
