pruning : 가중치의 중요도를 판단하는 기준을 이해하고 이를 통해 불필요한 연산을 제거하는 과정을 이해하고 있나. 
8~9일차 OnDeivce AI에서 자가 점검 포인트에 해당하는 부분이 어디야? 가중치의 중요도를 판단하는 기준을 이해하고 이를 통해 불필요한 연산을 제거하는 과정
```python
def prune_and_decode: 

# Layer별 KV pruning
for i, layer in enumerate(cache.layers):
    attn_kv = None

    if use_attn:
        attn = out.attentions[i]
        B, _, Q, K = attn.shape

        # GQA: 같은 KV head를 공유하는 Q head들의 attention 합산
        attn_kv = attn.view(B, n_kv, group, Q, K).sum(2)

    scores = score_fn(attn_kv, layer, budget)

    keep = scores.topk(budget, dim=-1).indices.sort(-1).values
    idx = keep.unsqueeze(-1).expand(-1, -1, -1, layer.keys.shape[-1])

    layer.keys   = layer.keys.gather(2, idx)
    layer.values = layer.values.gather(2, idx)
    
```

핵심코드는 아래와 같아.
```python

scores = score_fn(attn_kv, layer, budget)
keep = scores.topk(budget, dim=-1).indices.sort(-1).values

layer.keys   = layer.keys.gather(2, idx)
layer.values = layer.values.gather(2, idx)
```

- `score_fn()` → 토큰별 중요도 계산
- `topk(budget)` → 점수가 높은 토큰만 선택
- `gather()` → 선택된 토큰의 Key/Value만 남겨 캐시를 축소
