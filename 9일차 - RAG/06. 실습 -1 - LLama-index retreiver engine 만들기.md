> [!important] 정리 원칙
> - **실제 `.ipynb`의 코드 셀 내용을 그대로 인용**하고, 원본 셀 번호를 표기함.
> - 관련 셀을 **실행 순서대로 묶어** 앞뒤 맥락을 살림. 서로 떨어진 원본 셀은 따로 표기함.
> - `YOUR CODE HERE`도 원본에 있는 그대로 유지함. 이는 반드시 빈칸이라는 뜻은 아님.
> - 단계 사이 설명, 요약, 흐름도는 **학습용 추가 설명**이며 원본 코드는 아님.
> - 코랩 API 키, 데이터 파일 및 의존 패키지 설치 필요. 웹/API 호출 결과는 포함하지 않음.

## 전체 연결 관계

```text
[원본 데이터] → [Document 로드] → [Node/Chunk 분할] → [Embedding + VectorStoreIndex]
                                                    ↓
질문(query) → index.as_retriever() → retriever.retrieve(query) → 관련 Node
                                                    ↓
                                    Synthesizer 또는 LLM → 답변
```

- **Index 생성**: `VectorStoreIndex.from_documents(documents)`
- **Retriever 준비**: `index.as_retriever()`
- **실제 검색**: `retriever.retrieve(question)`
- **검색 결과 사용**: `node.text`, `n.node.get_content()`, `synthesize(...)`



# index 파일에 내용 추가하는 법 

![[Pasted image 20261112151906.png]]




```python


# =====================================================
# 1. 라이브러리 Import
# =====================================================
import os
import urllib.request

from google.colab import userdata
from llama_index.core import (
    SimpleDirectoryReader,
    VectorStoreIndex,
    get_response_synthesizer
)

os.environ["OPENAI_API_KEY"] = userdata.get("OPENAI_API_KEY")
# =====================================================
# 2. 원본 문서 다운로드
# =====================================================
os.makedirs("data", exist_ok=True)
url = "https://raw.githubusercontent.com/run-llama/llama_index/main/docs/examples/data/paul_graham/paul_graham_essay.txt"
urllib.request.urlretrieve(
    url,
    "data/paul_graham_essay.txt"
)
# =====================================================
# 3. Document 생성
# =====================================================
documents = SimpleDirectoryReader("data").load_data()
# =====================================================
# 4. Vector Index 생성
#    내부적으로 Chunk 분할 + Embedding 수행
# =====================================================
index = VectorStoreIndex.from_documents(documents)
# =====================================================
# 5. Retriever 생성
# =====================================================
retriever = index.as_retriever(similarity_top_k=2)
# =====================================================
# 6. Response Synthesizer 생성
# =====================================================
synthesizer = get_response_synthesizer(
    response_mode="compact"
)
# =====================================================
# 7. 질문 → 검색 → 답변 생성
# =====================================================
query = "What did the author do growing up?"
# 관련 문서 검색
nodes = retriever.retrieve(query)

# 검색한 문서를 참고해 LLM 답변 생성
response = synthesizer.synthesize(query, nodes)

print(response)


```

# 먼저 `StandardQueryEngine` 클래스를 정의해.

```python

class StandardQueryEngine(CustomQueryEngine):
    retriever: BaseRetriever
    response_synthesizer: BaseSynthesizer

    def custom_query(self, query_str: str):
        nodes = self.retriever.retrieve(query_str)
        response_obj = self.response_synthesizer.synthesize(query_str, nodes)
        return response_obj
```

그리고 76번 셀에서 실제로 연결해.

```python

retriever = index.as_retriever()
synthesizer = get_response_synthesizer(response_mode="compact")

query_engine = StandardQueryEngine(
    retriever=retriever,
    response_synthesizer=synthesizer
)

response = query_engine.query("What did the author do growing up?")
print(str(response))
```
